- [x] 盾兵：650+400；破盾切手枪并后撤；下回合恢复盾与近战。
- [x] 爆尸：贴近引信、击杀取消、爆炸 +100 感染、不伤建筑；盾兵背后扇形队友只受 50%。

- [x] 巨人：拆建筑 ×3、击退免疫数据。
- [x] BOSS 坦克：投石 7 秒间隔、2.5 秒首发、石块 2 秒预警、落点锁定、盾兵不侧移、击杀 400+50R 与英雄奖励。

- [x] 裂爪：260 内优先非盾人类；0.45 秒直线预警后冲刺，路径目标只吃一次伤害，冲刺后硬直 0.9 秒。
