# 平衡与性能记录

> 2026-10-18 · v1.1.0（人类自主 AI）

## 公式（与 `src/data/balance.js` 一致）

```
僵尸数量 N = 6 + 5R
僵尸 HP = 基础 × 1.06^(R-1)
僵尸伤害 = 基础 × 1.01^(R-1)，上限 +50%
僵尸速度 = 基础 × min(1.25, 1 + 0.005(R-1))
击杀金 = floor(基础 × (1 + 0.03(R-1)) × (1 + 0.04×经济等级))
通关奖励 = floor((60 + 12R) × (1 + 0.08×经济等级))
BOSS HP = 1200 × 1.14^(R-1)
BOSS 石块 = 80 + 6R
BOSS 奖励 = 400 + 50R
人口上限 = min(80, 8 + 2R)
感染 DPS = 最大生命 × 0.0002 × 感染值
科技费用：火力/护甲 120×1.45^等级；经济/血清 100×1.40^等级
```

波次构成采用“最大余数法”，与计划书 5.3 的 R1–R7 整数表逐项一致（测试断言）。

## 性能基准

### Node（`node tests/bench.js`）

```
entities: 300 zombies, 99 humans, 100 projectiles
steps=600
avgStepMs=1.358 maxStepMs=10.694
```

人类自主 AI（移动、寻医、分离）使单步模拟从 0.95ms 增至约 1.36ms，仍远低于 4ms 预算。

### 浏览器（Canvas 1269×714，DPR 1，headless Chromium）

| 项目 | 平均 |
|---|---:|
| `Sim.step` | 1.70 ms |
| `Renderer.draw + HUD.render` | 4.65 ms |
| 合计预算 | ≈157 FPS |

300 僵尸场景下模拟 + 渲染均在计划书预算（模拟 ≤4ms、渲染 ≤6ms）内。

### 调参入口

- 整体难度：`balance.js` 的 `1.06` 与 `6+5R`。
- 前期经济：初始 400 / 通关奖励 / 击杀金。
- BOSS：`1.14` 底数与 `80+6R`。
- 兵种：`data/humans.js`；僵尸：`data/zombies.js`。
- 出怪节奏：`constants.js` 的批次参数与 `waves.js`。

## 已知平衡观察

- 郊区公路 R1–R20 节奏稳定，R28 前后出现明显压力峰值。
- 医院广场与地铁站台在首个 BOSS（R7）附近明显更难；这是地图差异，不是全局倍率。
- 金钱在 R20 后增长快于支出，建议后续给后期科技/建筑增加更多出口（未在首版实现）。
