# 里程碑 M1–M4（交付记录）

> 依据 `docs/game-plan.md` 第 14 章与实现方案第 4–7 章。
> 完成日期：2026-10-18

## M1 纵向切片

**Objective**：郊区公路 + 4 人类 + 2 僵尸 + 完整回合循环 + HUD + 测试钩子。

**Scope**
- 工程骨架、常量、确定性 RNG、事件总线、几何、状态、空间哈希。
- 32px 导航网格 + 多源 BFS 流场；郊区公路地图。
- 手枪/霰弹/盾兵/治疗兵；普通/狂尸。
- 整备、招募、拖拽、出售、开始回合、清场结算、失败、重开。
- 顶部 HUD、底部招募面板、收入明细、游戏结束弹窗、`window.__game`。

**Acceptance Criteria**
- [x] 10 回合可玩，控制台无错误。
- [x] 100 僵尸场景 60 FPS（渲染预算实测通过）。
- [x] 同种子 + 同命令哈希一致。
- [x] `__game.tick()` 可确定性推进一回合。

**Exit Condition**：用户从菜单进入郊区公路，布阵后点击开始，能完整打完一回合并进入下一回合整备。

## M2 完整内容

**Objective**：8 人类、6 僵尸、感染完整、6 建筑、平民、队长、3 地图。

**Scope**
- 机枪/喷火/导弹/平民；盾尸/爆尸/母体/巨人/幼体/转化丧尸。
- 感染全来源、血清、医疗站、护盾弧、嘲讽、爆尸引信、母体爆仔、巨人拆建筑。
- 建筑槽位/废墟/光环/地雷；队长晋升与死亡爆炸。
- 医院广场、地铁站台；选图界面；8 卡招募、6 卡建筑、科技占位。

**Acceptance Criteria**
- [x] 20 回合可玩（bot 与手动均可）。
- [x] 感染能治疗/致死/变丧尸。
- [x] 队长每 3 回合晋升。
- [x] 建筑能被巨人/母体拆。
- [x] 3 张地图通过满建可达与绕行 ≤1.35× 校验。

**Exit Condition**：三张图均可进入、布阵、打完 R3 以上；感染/建筑/队长均实际触发。

## M3 BOSS、英雄与科技

**Objective**：BOSS、4 英雄、科技树、无头 bot、40 回合。

**Scope**
- BOSS 坦克：石块预警/落点侧移/践踏/奖励。
- 长官导弹、武士剑气、加特林鼓舞、疫医转化/群体治疗。
- 英雄随机奖励、重复强化、重伤回归；转化兵寿命与上限。
- 四条科技线 0–10 级；无头 bot 与 20/40 回合报告。

**Acceptance Criteria**
- [x] 40 回合可玩（bot seed 1 到 R42）。
- [x] BOSS 每 7 回合出现，血量/石块/奖励正确。
- [x] 英雄优先未拥有，集齐后强化。
- [x] 转化兵 3 回合消失、不占人口、最多 15。
- [x] bot 20/40 无异常。

**Exit Condition**：完整打一局到 R40 或失败；BOSS 预警、英雄技能、队长晋升、转化兵、科技满级表现正常。

## M4 打磨与发布

**Objective**：粒子/震屏/音效/教学/成绩/性能/QA/PWA/手机。

**Scope**
- 粒子、伤害数字、震屏、程序音效、命中反馈。
- 新手引导、图鉴/帮助、战斗日志、结算/失败弹窗。
- 最佳回合、设置、导出/导入存档。
- PWA manifest/SW/图标/OG、更新提示、离线缓存。
- 响应式舞台布局（战场 + 独立底栏）、横屏、触控 pointer 事件、竖屏遮罩。

**Acceptance Criteria**
- [x] 300 僵尸 + 99 人类 + 100 投射物：Node 模拟 ≈0.9ms/步；浏览器模拟 1.7ms + 渲染/HUD 4.65ms。
- [x] 手机横屏可玩；竖屏显示提示；触控目标 ≥44px（主要按钮）。
- [x] PWA 可安装设计就绪；SW 缓存 `zd-v1.0.0`，断网刷新可玩。
- [x] 无控制台错误（file:// 与 http 均验证）。
- [x] 文档同步（README、STATE、balance-notes、qa/checklist）。

**Exit Condition**：桌面与窄屏浏览器均能完成一局；刷新后设置/最佳回合保留；断网仍可进入游戏。
