# 尸潮防线 v1.2 详细实现方案

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 v1.1 的「部署区站桩 + 固定槽位/出生点 + 火箭兵一家独大」改造成 v1.2 的「人类小队自主搜索与结阵、僵尸四面来袭、建筑自由摆放且有数量上限、手机横屏/竖屏自适应可玩」。

**Architecture:** 保留 1280×720 固定世界、`1/60` 固定步长、零依赖经典脚本。新增 `src/sim/squads.js` 作为人类编队纯模拟模块；`ai.js` 只负责把编队阵位转化为移动与攻击。删除 `map.deploy / map.slots / map.spawns` 三个运行时概念，改为「世界边界 + 形状碰撞 + 动态人类源流场 + 四边屏幕外出生」。建筑变成带形状与数量上限的自由实体。视图层改为「画布铺满顶栏以下、底栏以上，世界等比居中，HUD 全宽 + 安全区 + 可滚动弹窗」，首次手势尝试全屏横屏，失败则竖屏可玩。

**Tech Stack:** 原生 JavaScript（ES5 风格 IIFE）、Canvas 2D、DOM HUD、CSS、Node 内置测试（`node --test`）、无 npm 运行时依赖、无构建步骤。

**Spec:** `docs/superpowers/plans/2026-10-19-v1.2-ai-layout-rebalance.md`（下称「源计划」）§1「需求与决策基线」；玩法真相最终同步到 `docs/game-plan.md`。

**文档关系与冲突裁决：** 本文件是源计划的实现级伴随文档。冲突时按以下优先级：用户已确认决策（源计划 §1.2） → 本方案 §1.2「源计划校正」 → 源计划其余部分 → 现有代码。本方案不改变源计划 §1.3 的非目标。

## Global Constraints

以下约束来自 `AGENTS.md`，每个任务都隐含适用：

- **运行时零依赖、零构建**：不引入 npm 包、打包器、ES module、外部字体/图片/音频。所有资源本地静态。
- **`file://` 必须可玩**：不能用 ES module / `fetch` 加载游戏代码 / Service Worker 作为必需路径。
- **加载顺序唯一真相**：所有脚本只在 `index.html` 中按顺序声明；测试用 `tests/load-sim.js` 解析它。新增 `src/sim/squads.js` 时必须同时更新 `index.html` 与 `sw.js`。
- **分层**：`src/core` ← `src/data` ← `src/sim` ← `src/view` / `src/main.js`。`src/sim/**`、`src/data/**`、`src/core/**` 不得访问 `document`、`window`、`localStorage`、`Math.random()`、`Date.now()`、`performance.now()`。
- **确定性**：模拟随机一律走 `state.rng.*`；同种子 + 同整备期命令必须得到相同 `ZG.State.hash()`。所有编队/目标选择排序必须显式指定 `id` 决胜，不得依赖对象遍历顺序。
- **固定步长**：`ZG.Const.STEP_SEC = 1/60`，不得用帧数当时间。编队重建、流场刷新都按 `state.battle.stepCount` 或固定 `dt` 计时。
- **数值集中**：单位/僵尸/英雄/建筑/地图/波次/公式只写在 `src/data/**`；`src/sim/**` 不写魔法数字。本计划新增参数全部进入 `src/data/humans.js`、`src/data/buildings.js`、`src/data/zombies.js`、`src/core/constants.js`。
- **中文文案**：所有玩家可见文字为简体中文；代码标识符用英文。
- **可访问性**：颜色之外有符号/文字/形状；伤害数字与震屏可关；暂停随时可用。
- **每个任务结束必须 `npm test` 全绿**；最终必须运行 `node tests/bench.js`、`node tests/bot.js --rounds 40 --seed 1`，并完成浏览器手验后才能声称完成。

## Review Focus

以下五类输入/条件最容易「看起来能跑但实际不能玩」。每一条都必须在对应任务里有测试或明确验收步骤：

1. **无敌人时的全图搜索**：所有僵尸清空但还有未出生批次时，人类不能原地发呆、不能在地图边缘来回抖动、不能走回原始放置点；应朝最近的待出生边缘推进并在距边界 `searchStopInset=120` 处停住。
2. **任意位置放置**：人类/建筑放在地图四角、紧贴障碍、紧贴已有建筑时必须给出正确结果；不能出现放进去后卡死、指针坐标偏移、拖拽穿墙。矩形墙的「中心坐标」与 `Geom` 的「左上角矩形」换算必须唯一。
3. **盾尸拦截的边界**：多个盾尸同时在射线附近、盾尸背对射手、盾尸盾值已破、火箭/药瓶/霰弹多弹丸时，必须只拦截「正面、有盾、最近」的那一只；火焰与近战不被拦截。
4. **手机宽屏/竖屏/安全区**：20:9 宽屏手机的左右区域、刘海/底部手势条、竖屏降级布局下，设置弹窗最后一项必须能滚动到、所有按钮可点、战场指针坐标不能偏移。
5. **平衡回归**：纯火箭兵不得再稳定打到 R40；混合阵容仍应能通关；建筑上限必须真正阻止「全图堆满哨塔/墙」。

## 2. 总体设计

### 2.1 模块与加载顺序

`index.html` 在 `src/sim/pathing.js` 之后、`src/sim/ai.js` 之前插入：

```html
<script src="src/sim/squads.js"></script>
```

`sw.js` 的 `SHELL` 同步加入 `'./src/sim/squads.js'`。

`src/sim/squads.js` 的职责：

- 纯模拟：只读 `state.humans`、`state.zombies`、`state.spawner`、`state.map`；
- 写 `state.squads`、`h.squadId/squadTier/formationX/formationY`；
- 不访问 DOM、不使用随机、不写 `Math.random/Date.now/performance.now`。

|---|---|
| 世界 | `1280×720`，原点左上，`y` 向下，角度弧度 |
| 建筑中心 | `b.x/b.y` 是中心；围墙 `w/h` 随 `vertical` 交换 |
| `Geom` 矩形 | **左上角** `(x, y, w, h)`；与建筑中心换算用 `rectOfCenter` |
| 世界边界 | 中心坐标 `[radius+4, W-radius-4]`；矩形 `[4, W-4]` |
| 画布 | CSS 像素尺寸 `cssW×cssH`；世界按 `scale=min(cssW/W,cssH/H)` 等比居中 |
| 指针 | `toWorld` 先减 canvas 的 `rect.left/top`，再减 `worldRect.offset`，再除 `worldRect.scale`；落在世界外返回 `null` |
| 射线 | `segmentCircleT` 返回 0..1 的首次相交参数；拦截只接受 `0<t<1` |

### 2.4 确定性规则

1. 所有数组排序最终决胜用 `(a.id - b.id)`；无 id 的出生点用 `(x, y)`。
2. 目标选择使用严格 `<` 与 `id` 决胜，不依赖 `state.zombies` 的插入顺序。
3. 编队重建每 60 步一次；`markDirty` 立即重建；重建不重置 `frontX/frontY`。
4. 流场每 15 步重建一次；建造/摧毁/拆除立即重建。
5. 所有时间累计用 `dt = STEP_SEC`；不用 `Date.now/performance.now`。
6. 新逻辑不得引入 `Math.random()`；测试用 `ZG.Rng` 流。

```js
function circleOverlapsRect(cx, cy, r, rx, ry, rw, rh, gap) {
  const g = gap || 0;
  const nx = Math.max(rx, Math.min(rx + rw, cx));
  const ny = Math.max(ry, Math.min(ry + rh, cy));
  return dist2(cx, cy, nx, ny) < (r + g) * (r + g);
}
function rectOverlapsRect(ax, ay, aw, ah, bx, by, bw, bh, gap) {
  const g = gap || 0;
  return ax < bx + bw + g && ax + aw + g > bx &&
         ay < by + bh + g && ay + ah + g > by;
}
function distPointToRect(x, y, rx, ry, rw, rh) {
  const nx = Math.max(rx, Math.min(rx + rw, x));
  const ny = Math.max(ry, Math.min(ry + rh, y));
  return dist(x, y, nx, ny);
}
function segmentCircleT(x1, y1, x2, y2, cx, cy, r) {
  const dx = x2 - x1, dy = y2 - y1;
  const fx = x1 - cx, fy = y1 - cy;
  const a = dx * dx + dy * dy;
  if (a < 1e-12) return (fx * fx + fy * fy <= r * r) ? 0 : null;
  const b = 2 * (fx * dx + fy * dy);
  const c = fx * fx + fy * fy - r * r;
  const disc = b * b - 4 * a * c;
  if (disc < 0) return null;
  const s = Math.sqrt(disc);
  const t1 = (-b - s) / (2 * a);
  const t2 = (-b + s) / (2 * a);
  if (t1 >= 0 && t1 <= 1) return t1;
  if (t2 >= 0 && t2 <= 1) return t2;
  return null;
}
function clampToWorld(x, y, radius) {
  const m = (radius || 0) + 4;
  return {
    x: Math.max(m, Math.min(ZG.Const.W - m, x)),
    y: Math.max(m, Math.min(ZG.Const.H - m, y))
  };
}
function humanCentroid(state) {
  let sx = 0, sy = 0, n = 0;
  for (const h of state.humans) {
    if (!h.alive) continue;
    sx += h.x; sy += h.y; n++;
  }
  return n ? { x: sx / n, y: sy / n } : null;
}
function rectOfCenter(x, y, w, h) {
  return { x: x - w / 2, y: y - h / 2, w, h };
}
function rectOfBuilding(b) {
  if (b.shape === 'rect') return rectOfCenter(b.x, b.y, b.w, b.h);
  return rectOfCenter(b.x, b.y, (b.radius || 24) * 2, (b.radius || 24) * 2);
}
function isBlockedAt(state, x, y, radius) {
  const map = state.map;
  if (map && map.obstacles) {
    for (const ob of map.obstacles) {
      if (ob.kind === 'rect') {
        if (circleOverlapsRect(x, y, radius, ob.x, ob.y, ob.w, ob.h, 0)) return true;
      } else if (circleOverlapsCircle(x, y, radius, ob.x, ob.y, ob.r, 0)) {
        return true;
      }
    }
  }
  for (const b of state.buildings || []) {
    if (!b.alive) continue;
    const data = ZG.Data.buildings[b.typeId];
    if (data && data.blocks === false) continue;
    if (b.shape === 'rect') {
      const r = rectOfBuilding(b);
      if (circleOverlapsRect(x, y, radius, r.x, r.y, r.w, r.h, 0)) return true;
    } else if (circleOverlapsCircle(x, y, radius, b.x, b.y, b.radius || 24, 0)) {
      return true;
    }
  }
  return false;
}
```

```js
    return { ok: false, reason: 'outside' };
  }
  for (const h of state.humans) {
    if (!h.alive || h.id === ignoreId) continue;
    if (ZG.Geom.circleOverlapsCircle(x, y, radius, h.x, h.y, h.radius, 2)) {

  }
  for (const b of state.buildings) {

    if (b.shape === 'rect') {
      const r = ZG.Geom.rectOfBuilding(b);

      }
    } else if (ZG.Geom.circleOverlapsCircle(x, y, radius, b.x, b.y, b.radius || 24, 2)) {
      return { ok: false, reason: 'overlap' };
```

```js
function buildingDims(typeId, opts) {
  const data = ZG.Data.buildings[typeId];
  const vertical = !!(opts && opts.vertical) && data.rotatable !== false;
  const shape = data.shape || 'circle';
  const w = shape === 'rect' ? (vertical ? data.h : data.w) : (data.radius || 24) * 2;
  const h = shape === 'rect' ? (vertical ? data.w : data.h) : (data.radius || 24) * 2;
  return { data, shape, w, h, vertical, radius: data.radius || Math.max(w, h) / 2 };
}

function canPlaceBuilding(state, typeId, x, y, opts) {
  if (!state.map) return { ok: false, reason: 'outside' };
  const d = buildingDims(typeId, opts);
  if (d.shape === 'rect') {
    if (x - d.w / 2 < ZG.Const.PLACE_MARGIN ||
        y - d.h / 2 < ZG.Const.PLACE_MARGIN ||
        x + d.w / 2 > ZG.Const.W - ZG.Const.PLACE_MARGIN ||
        y + d.h / 2 > ZG.Const.H - ZG.Const.PLACE_MARGIN) {
      return { ok: false, reason: 'outside' };
    }
  } else {
    const m = d.radius + ZG.Const.PLACE_MARGIN;
    if (x < m || y < m || x > ZG.Const.W - m || y > ZG.Const.H - m) {
      return { ok: false, reason: 'outside' };
    }
  }
  const my = d.shape === 'rect' ? ZG.Geom.rectOfCenter(x, y, d.w, d.h) : null;
  const hitsCircle = (cx, cy, cr) => d.shape === 'rect'
    ? ZG.Geom.circleOverlapsRect(cx, cy, cr, my.x, my.y, my.w, my.h, ZG.Const.PLACE_GAP)
    : ZG.Geom.circleOverlapsCircle(x, y, d.radius, cx, cy, cr, ZG.Const.PLACE_GAP);
  const hitsRect = (r) => d.shape === 'rect'
    ? ZG.Geom.rectOverlapsRect(my.x, my.y, my.w, my.h, r.x, r.y, r.w, r.h, ZG.Const.PLACE_GAP)
    : ZG.Geom.circleOverlapsRect(x, y, d.radius, r.x, r.y, r.w, r.h, ZG.Const.PLACE_GAP);

  for (const ob of state.map.obstacles || []) {
    const hit = ob.kind === 'rect'
      ? hitsRect(ob)
      : hitsCircle(ob.x, ob.y, ob.r);
    if (hit) return { ok: false, reason: 'obstacle' };
  }
  for (const h of state.humans) {
    if (h.alive && hitsCircle(h.x, h.y, h.radius)) return { ok: false, reason: 'overlap' };
  }
  for (const b of state.buildings) {
    if (!b.alive) continue;
    const br = ZG.Geom.rectOfBuilding(b);
    const hit = b.shape === 'rect' ? hitsRect(br) : hitsCircle(b.x, b.y, b.radius || 24);
    if (hit) return { ok: false, reason: 'overlap' };
  }
  return { ok: true };
}
```

```js
function build(state, typeId, x, y, opts) {
  if (state.status !== 'prep') return { ok: false, reason: 'not-prep' };
  const data = ZG.Data.buildings[typeId];
  if (!data) return { ok: false, reason: 'unknown' };
  const count = state.buildings.filter(b => b.alive && b.typeId === typeId).length;
  if (data.limit !== undefined && count >= data.limit) {
    return { ok: false, reason: 'limit' };
  }
  if (!canAfford(state, data.cost)) return { ok: false, reason: 'money' };
  const p = canPlaceBuilding(state, typeId, x, y, opts);

  spend(state, data.cost);
  const b = ZG.State.spawnBuilding(state, typeId, x, y, opts);
  state.pathing = ZG.Pathing.build(state);
  return { ok: true, building: b };
}
```

```js
const EDGES = ['top', 'right', 'bottom', 'left'];

function spawnPoint(rng, edge) {
  const inset = ZG.Const.SPAWN_EDGE_INSET;
  const d = ZG.Const.SPAWN_OUT_MIN +
    rng.next() * (ZG.Const.SPAWN_OUT_MAX - ZG.Const.SPAWN_OUT_MIN);
  if (edge === 'top') return { x: inset + rng.next() * (ZG.Const.W - 2 * inset), y: -d, edge };
  if (edge === 'bottom') return { x: inset + rng.next() * (ZG.Const.W - 2 * inset), y: ZG.Const.H + d, edge };
  if (edge === 'left') return { x: -d, y: inset + rng.next() * (ZG.Const.H - 2 * inset), edge };
  return { x: ZG.Const.W + d, y: inset + rng.next() * (ZG.Const.H - 2 * inset), edge: 'right' };
}

function build(R, rng) {
  // ...composition/types/shuffle/batch 逻辑不变...
  // BOSS 搬移逻辑不变
  let at = ZG.Const.SPAWN_FIRST_DELAY;
  for (let i = 0; i < batches.length; i++) {
    const b = batches[i];
    if (i > 0) at += ZG.Const.BATCH_GAP_MIN + rng.next() * (ZG.Const.BATCH_GAP_MAX - ZG.Const.BATCH_GAP_MIN);
    b.at = at;
    b.portalAt = at - ZG.Const.SPAWN_WARN;
    b.warned = false;
    for (let j = 0; j < b.spawns.length; j++) {

      Object.assign(b.spawns[j], sp);
```

**5.3.1 `Pathing.build`**

```js
function build(state) {
  const blocked = new Uint8Array(COLS * ROWS);
  const map = state.map;

  for (const ob of (map && map.obstacles) || []) {
    if (ob.kind === 'rect') markRect(blocked, ob.x, ob.y, ob.w, ob.h);
    else markCircle(blocked, ob.x, ob.y, ob.r);
  }
  for (const b of state.buildings || []) {
    if (!b.alive) continue;
    const data = ZG.Data.buildings[b.typeId];
    if (data && data.blocks === false) continue;
    if (b.shape === 'rect') {
      const r = ZG.Geom.rectOfBuilding(b);
      markRect(blocked, r.x, r.y, r.w, r.h);
    } else {
      markCircle(blocked, b.x, b.y, b.radius || 24);
    }
  }

  const dist = new Uint16Array(COLS * ROWS).fill(INF);
  const dirX = new Int8Array(COLS * ROWS);
  const dirY = new Int8Array(COLS * ROWS);
  const queue = new Int32Array(COLS * ROWS);
  let head = 0, tail = 0;

  const sources = [];
  for (const h of state.humans || []) {
    if (!h.alive) continue;
    const c = cellOf(h.x, h.y);
    if (!blocked[c.i]) sources.push(c.i);
  }
  if (!sources.length) {
    const c = cellOf(ZG.Const.W / 2, ZG.Const.H / 2);
    if (!blocked[c.i]) sources.push(c.i);
  }
  for (const i of sources) {
    if (dist[i] !== INF) continue;
    dist[i] = 0;
    queue[tail++] = i;
  }

  while (head < tail) {
    const i = queue[head++];
    const cx = i % COLS;
    const cy = (i / COLS) | 0;
    const d = dist[i] + 1;
    if (cx > 0) visit(i - 1, cx - 1, cy, -1, 0, d);
    if (cx < COLS - 1) visit(i + 1, cx + 1, cy, 1, 0, d);
    if (cy > 0) visit(i - COLS, cx, cy - 1, 0, -1, d);
    if (cy < ROWS - 1) visit(i + COLS, cx, cy + 1, 0, 1, d);
  }

  function visit(ni, ncx, ncy, dx, dy, d) {
    if (blocked[ni] || dist[ni] !== INF) return;
    dist[ni] = d;
    dirX[ni] = -dx;
    dirY[ni] = -dy;
    queue[tail++] = ni;
  }

  const center = ZG.Geom.humanCentroid(state) || { x: ZG.Const.W / 2, y: ZG.Const.H / 2 };
  return { cols: COLS, rows: ROWS, cell: CELL, blocked, dist, dirX, dirY,
    centerX: center.x, centerY: center.y, mapId: map ? map.id : '' };
}
```

```js
function markCircle(blocked, x, y, r) {
  const x0 = Math.max(0, Math.floor((x - r - CELL) / CELL));
  const x1 = Math.min(COLS - 1, Math.ceil((x + r + CELL) / CELL));
  const y0 = Math.max(0, Math.floor((y - r - CELL) / CELL));
  const y1 = Math.min(ROWS - 1, Math.ceil((y + r + CELL) / CELL));
```

```js
function directionAt(pathing, x, y) {
  if (!pathing) return { x: 0, y: 0 };
  const c = cellOf(x, y);
  if (pathing.dist[c.i] === INF || (pathing.dirX[c.i] === 0 && pathing.dirY[c.i] === 0)) {
    const dx = pathing.centerX - x, dy = pathing.centerY - y;
    const len = Math.hypot(dx, dy) || 1;
    return { x: dx / len, y: dy / len };
  }
  const dx = pathing.dirX[c.i], dy = pathing.dirY[c.i];
  const len = Math.hypot(dx, dy) || 1;
  return { x: dx / len, y: dy / len };
}

function nearestReachable(pathing, x, y) {
  if (!pathing) return { x, y };
  const c = cellOf(x, y);
  if (pathing.dist[c.i] !== INF) return { x: cellCX(c.cx), y: cellCY(c.cy) };
  for (let r = 1; r <= 20; r++) {
    for (let dy = -r; dy <= r; dy++) for (let dx = -r; dx <= r; dx++) {
      if (Math.max(Math.abs(dx), Math.abs(dy)) !== r) continue;
      const nx = c.cx + dx, ny = c.cy + dy;
      if (nx < 0 || ny < 0 || nx >= COLS || ny >= ROWS) continue;
      const ni = idx(nx, ny);
      if (pathing.dist[ni] !== INF) return { x: cellCX(nx), y: cellCY(ny) };
    }
  }
  return { x: pathing.centerX, y: pathing.centerY };
}
```

```js
function validate(map) {
  const fake = {
    map,
    humans: [{ id: 0, alive: true, x: ZG.Const.W / 2, y: ZG.Const.H / 2, radius: 8 }],
    buildings: []
  };
  const p = build(fake);
  let ok = true, maxDetour = 0;
  const problems = [];
  const check = (x, y) => {
    const c = cellOf(x, y);
    if (p.blocked[c.i]) return;
    if (p.dist[c.i] === INF) { ok = false; problems.push('unreachable ' + x + ',' + y); return; }
    const straight = Math.max(1, ZG.Geom.dist(x, y, p.centerX, p.centerY));
    maxDetour = Math.max(maxDetour, (p.dist[c.i] * CELL) / straight);
  };
  for (let cx = 0; cx < COLS; cx++) { check(cellCX(cx), cellCY(0)); check(cellCX(cx), cellCY(ROWS - 1)); }
  for (let cy = 0; cy < ROWS; cy++) { check(cellCX(0), cellCY(cy)); check(cellCX(COLS - 1), cellCY(cy)); }
  check(p.centerX, p.centerY);
  return { ok, maxDetour, problems, detourOk: true };
}
```

```js
function pushOutRect(z, nx, ny, b) {
  const r = ZG.Geom.rectOfBuilding(b);
  const px = Math.max(r.x, Math.min(r.x + r.w, nx));
  const py = Math.max(r.y, Math.min(r.y + r.h, ny));
  const dx = nx - px, dy = ny - py;
  const d = Math.hypot(dx, dy);
  if (d > 1e-9) {
    if (d < z.radius) {
      nx = px + (dx / d) * (z.radius + 1);
      ny = py + (dy / d) * (z.radius + 1);
    }
  } else {
    const left = nx - r.x, right = r.x + r.w - nx;
    const top = ny - r.y, bottom = r.y + r.h - ny;
    const m = Math.min(left, right, top, bottom);
    if (m === left) nx = r.x - z.radius - 1;
    else if (m === right) nx = r.x + r.w + z.radius + 1;
    else if (m === top) ny = r.y - z.radius - 1;
    else ny = r.y + r.h + z.radius + 1;
  }
  return { x: nx, y: ny };
}
```

**6.3.2 `src/sim/squads.js` 算法**

```js
(function () {
  'use strict';
  const ZG = globalThis.ZG = globalThis.ZG || {};
  const STEP = ZG.Const.STEP_SEC;

  function cfg() { return ZG.Data.humanAi.squad; }
  function byId(state) {
    const m = new Map();
    for (const h of state.humans) if (h.alive) m.set(h.id, h);
    return m;
  }
  function isCore(h) { return h.classId === 'shield' && !h.shieldBroken; }
  function centroid(list) {
    if (!list.length) return { x: ZG.Const.W / 2, y: ZG.Const.H / 2 };
    let x = 0, y = 0;
    for (const h of list) { x += h.x; y += h.y; }
    return { x: x / list.length, y: y / list.length };
  }
  function nearestSquad(squads, x, y) {
    let best = squads[0], bd = Infinity;
    for (const s of squads) {
      const d = ZG.Geom.dist2(x, y, s.anchorX, s.anchorY);
      if (d < bd || (d === bd && s.id < best.id)) { bd = d; best = s; }
    }
    return best;
  }
  function makeSquad(id, core) {
    return {
      id, coreId: core ? core.id : null,
      shieldIds: core ? [core.id] : [],
      memberIds: [], civilianIds: [], tiers: {},
      anchorX: core ? core.x : ZG.Const.W / 2,
      anchorY: core ? core.y : ZG.Const.H / 2,
      frontX: core ? core.x : ZG.Const.W / 2,
      frontY: core ? core.y : ZG.Const.H / 2,
      faceAngle: -Math.PI / 2,
      targetX: ZG.Const.W / 2, targetY: ZG.Const.H / 2,
      targetZombieId: 0, mode: 'hold'
    };
  }

  function rebuild(state) {
    const c = cfg();
    const humans = state.humans.filter(h => h.alive).slice().sort((a, b) => a.id - b.id);
    const cores = humans.filter(isCore);
    const combat = humans.filter(h => h.classId !== 'civilian' && !isCore(h));
    const civs = humans.filter(h => h.classId === 'civilian');
    const old = new Map(state.squads.map(s => [s.id, s]));
    const squads = [];

    for (const core of cores) {
      const prev = old.get(core.id);
      const s = prev ? Object.assign({}, prev) : makeSquad(core.id, core);
      s.coreId = core.id; s.shieldIds = [core.id]; s.depthOffset = 0;
      s.memberIds = []; s.civilianIds = []; s.tiers = {};
      core.squadId = s.id; core.squadTier = 0;
      squads.push(s);
    }
    if (!squads.length) {
      const prev = old.get(0);
      const s = prev ? Object.assign({}, prev) : makeSquad(0, null);
      s.coreId = null; s.shieldIds = [];
      s.memberIds = []; s.civilianIds = []; s.tiers = {};
      squads.push(s);
    }

    const map = byId(state);
    for (const h of combat) {
      let chosen = null;
      if (h.squadId != null) {
        const prev = squads.find(s => s.id === h.squadId);
        if (prev && ZG.Geom.dist(h.x, h.y, prev.anchorX, prev.anchorY) <=
            c.joinRadius * c.keepRadiusMul) chosen = prev;
      }
      if (!chosen) chosen = nearestSquad(squads, h.x, h.y);
      chosen.memberIds.push(h.id);
      h.squadId = chosen.id;
      h.squadTier = 0;
    }
    for (const h of civs) {
      let chosen = null;
      if (h.squadId != null) {
        const prev = squads.find(s => s.id === h.squadId);
        if (prev && ZG.Geom.dist(h.x, h.y, prev.anchorX, prev.anchorY) <=
            c.joinRadius * c.keepRadiusMul) chosen = prev;
      }
      if (!chosen) chosen = nearestSquad(squads, h.x, h.y);
      chosen.civilianIds.push(h.id);
      h.squadId = chosen.id;
      h.squadTier = 0;
    }

    for (const s of squads) {
      const members = s.memberIds.map(id => map.get(id)).filter(Boolean);
      members.sort((a, b) => {
        const da = ZG.Geom.dist2(a.x, a.y, s.anchorX, s.anchorY);
        const db = ZG.Geom.dist2(b.x, b.y, s.anchorX, s.anchorY);
        return (da - db) || (a.id - b.id);
      });
      s.memberIds = members.map(h => h.id);
      members.forEach((h, i) => { h.squadTier = Math.floor(i / c.capacity); });

      const core = s.coreId != null ? map.get(s.coreId) : null;
      if (core) {
        s.anchorX = core.x; s.anchorY = core.y;
      } else {
        const list = members.length ? members : s.civilianIds.map(id => map.get(id)).filter(Boolean);
        const p = centroid(list);
        s.anchorX = p.x; s.anchorY = p.y;
      }

      // 无盾小队：把最浅的职业深度归零，避免远程被"虚拟盾线"推到更后面
      if (s.shieldIds.length) {
        s.depthOffset = 0;
      } else {
        let minDepth = Infinity;
        for (const id of s.memberIds) {
          const h = map.get(id);
          if (!h) continue;
          const d = c.roleDepth[h.role] !== undefined ? c.roleDepth[h.role] : c.roleDepth.rifle;
          minDepth = Math.min(minDepth, d);
        }
        s.depthOffset = minDepth === Infinity ? c.roleDepth.civilian : minDepth;
      }
    }

    state.squads = squads.sort((a, b) => a.id - b.id);
    state.squadDirty = false;
    state.squadTimer = 0;
    recomputeSlots(state);
    return state.squads;
  }

  function squadSpeed(state, s) {
    const c = cfg();
    const map = byId(state);
    const core = s.coreId != null ? map.get(s.coreId) : null;
    let speed = c.squadSpeedCap;
    if (core) speed = Math.min(speed, core.moveSpeed);
    else {
      let fastest = 0;
      for (const id of s.memberIds) {
        const h = map.get(id);
        if (!h) continue;
        if (h.role === 'melee' || h.role === 'flame' || h.role === 'shotgun') {
          fastest = Math.max(fastest, h.moveSpeed);
        }
      }
      if (fastest > 0) speed = Math.min(speed, fastest);
    }
    return speed;
  }

  function engageRange(state, s) {
    const c = cfg();
    const map = byId(state);
    const offset = s.depthOffset || 0;
    const frontRoles = { tank: 1, melee: 1, flame: 1, shotgun: 1 };
    let bestFront = Infinity, bestAny = Infinity;
    for (const id of s.memberIds) {
      const h = map.get(id);
      if (!h || !h.attack) continue;
      const base = c.roleDepth[h.role] !== undefined ? c.roleDepth[h.role] : c.roleDepth.rifle;
      const depth = Math.max(0, base + (h.squadTier || 0) * c.overflowTierDepth - offset);
      const effective = ZG.Stats.human(state, h).range - depth;
      bestAny = Math.min(bestAny, effective);
      if (frontRoles[h.role]) bestFront = Math.min(bestFront, effective);
    }
    const best = isFinite(bestFront) ? bestFront : bestAny;
    if (!isFinite(best)) return Infinity; // 纯平民/无武器小队不推进
    return Math.max(20, best);
  }

  function nearestZombieTo(state, x, y, used) {
    let best = null, bd = Infinity;
    for (const z of state.zombies) {
      if (!z.alive) continue;
      if (used && used.has(z.id)) continue;
      const d = ZG.Geom.dist2(x, y, z.x, z.y);
      if (d < bd || (d === bd && best && z.id < best.id)) { bd = d; best = z; }
    }
    return best;
  }

  function pendingSpawnPoint(state, x, y) {
    let best = null, bd = Infinity;
    const sp = state.spawner;
    for (let i = sp.batchIndex; i < sp.batches.length; i++) {
      for (const s of sp.batches[i].spawns) {
        const d = ZG.Geom.dist2(x, y, s.x, s.y);
        if (d < bd || (d === bd && best && (s.x < best.x || (s.x === best.x && s.y < best.y)))) {
          bd = d; best = s;
        }
      }
    }
    return best;
  }

  function advanceFront(state, s, dt) {
    const step = squadSpeed(state, s) * dt;
    const dirX = Math.cos(s.faceAngle), dirY = Math.sin(s.faceAngle);
    const perpX = -dirY, perpY = dirX;
    const tries = [[0, 0], [0.85, 0], [-0.85, 0], [1.5, 0], [-1.5, 0]];
    for (const t of tries) {
      const ca = Math.cos(t[0]), sa = Math.sin(t[0]);
      const vx = dirX * ca - dirY * sa;
      const vy = dirX * sa + dirY * ca;
      const p = ZG.Geom.clampToWorld(s.frontX + vx * step, s.frontY + vy * step, 16);
      if (!ZG.Geom.isBlockedAt(state, p.x, p.y, 16)) {
        s.frontX = p.x; s.frontY = p.y;
        return true;
      }
    }
    for (const k of [1, -1, 2, -2]) {
      const p = ZG.Geom.clampToWorld(
        s.frontX + perpX * cfg().shieldSpacing * k,
        s.frontY + perpY * cfg().shieldSpacing * k, 16);
      if (!ZG.Geom.isBlockedAt(state, p.x, p.y, 16)) {
        s.frontX = p.x; s.frontY = p.y;
        return true;
      }
    }
    return false;
  }

  function update(state) {
    const c = cfg();
    if (state.squadDirty || state.squadTimer >= c.rebuildSec) rebuild(state);
    state.squadTimer += STEP;
    if (!state.squads.length) return;

    const used = new Set();
    const squads = state.squads.slice().sort((a, b) => a.id - b.id);
    for (const s of squads) {
      let target = null;
      if (state.zombies.length) {
        target = nearestZombieTo(state, s.frontX, s.frontY, used);
        if (!target) target = nearestZombieTo(state, s.frontX, s.frontY, null);
        if (target) used.add(target.id);
      }
      if (target) {
        s.targetZombieId = target.id;
        s.targetX = target.x; s.targetY = target.y;
        s.faceAngle = Math.atan2(target.y - s.frontY, target.x - s.frontX);
        const d = ZG.Geom.dist(s.frontX, s.frontY, target.x, target.y);
        if (d > engageRange(state, s)) { s.mode = 'advance'; advanceFront(state, s, STEP); }
        else s.mode = 'hold';
      } else {
        const p = pendingSpawnPoint(state, s.frontX, s.frontY);
        const goal = p
          ? {
              x: Math.max(c.searchStopInset, Math.min(ZG.Const.W - c.searchStopInset, p.x)),
              y: Math.max(c.searchStopInset, Math.min(ZG.Const.H - c.searchStopInset, p.y))
            }
          : { x: ZG.Const.W / 2, y: ZG.Const.H / 2 };
        s.targetZombieId = 0;
        s.targetX = goal.x; s.targetY = goal.y;
        s.faceAngle = Math.atan2(goal.y - s.frontY, goal.x - s.frontX);
        if (s.memberIds.length > 0 &&
            ZG.Geom.dist(s.frontX, s.frontY, goal.x, goal.y) > 2) {
          s.mode = 'search';
          advanceFront(state, s, STEP);
        } else {
          s.mode = 'hold';
        }
      }
      s.anchorX = s.frontX;
      s.anchorY = s.frontY;
    }
    recomputeSlots(state);
  }

  function recomputeSlots(state) {
    const c = cfg();
    const map = byId(state);
    for (const s of state.squads) {
      const face = s.faceAngle;
      const dx = Math.cos(face), dy = Math.sin(face);
      const perpX = -dy, perpY = dx;
      const backX = -dx, backY = -dy;
      const slot = (lateral, depth) => ({
        x: s.frontX + perpX * lateral + backX * depth,
        y: s.frontY + perpY * lateral + backY * depth
      });

      // 盾兵
      const shields = s.shieldIds.map(id => map.get(id)).filter(Boolean).sort((a, b) => a.id - b.id);
      for (let i = 0; i < shields.length; i++) {
        const row = Math.floor(i / 4);
        const col = i % 4;
        const nInRow = Math.min(4, shields.length - row * 4);
        const lateral = (col - (nInRow - 1) / 2) * c.shieldSpacing + (row ? c.shieldSpacing / 2 : 0);
        const depth = row * 26;
        const p = slot(lateral, depth);
        const q = ZG.Geom.clampToWorld(p.x, p.y, shields[i].radius);
        shields[i].formationX = q.x;
        shields[i].formationY = q.y;
      }

      // 非盾单位按深度桶分组，避免火箭/治疗同深度重叠
      const buckets = [
        { roles: ['melee'], depth: c.roleDepth.melee },
        { roles: ['flame'], depth: c.roleDepth.flame },
        { roles: ['shotgun'], depth: c.roleDepth.shotgun },
        { roles: ['rifle'], depth: c.roleDepth.rifle },
        { roles: ['rocket', 'medic'], depth: c.roleDepth.rocket }
      ];
      for (const bucket of buckets) {
        const list = [];
        for (const id of s.memberIds) {
          const h = map.get(id);
          if (!h) continue;
          if (bucket.roles.indexOf(h.role) >= 0) list.push(h);
        }
        list.sort((a, b) => {
          const ra = bucket.roles.indexOf(a.role), rb = bucket.roles.indexOf(b.role);
          return (ra - rb) || (a.id - b.id);
        });
        for (let i = 0; i < list.length; i++) {
          const h = list[i];
          const row = Math.floor(i / c.rowMax);
          const col = i % c.rowMax;
          const nInRow = Math.min(c.rowMax, list.length - row * c.rowMax);
          const lateral = (col - (nInRow - 1) / 2) * c.lateralSpacing;
          const depth = Math.max(0, bucket.depth - (s.depthOffset || 0)) +
            (h.squadTier || 0) * c.overflowTierDepth + row * c.rowSpacing;
          const p = slot(lateral, depth);
          const q = ZG.Geom.clampToWorld(p.x, p.y, h.radius);
          h.formationX = q.x;
          h.formationY = q.y;
        }
      }

      // 平民
      const civs = s.civilianIds.map(id => map.get(id)).filter(Boolean).sort((a, b) => a.id - b.id);
      for (let i = 0; i < civs.length; i++) {
        const h = civs[i];
        const row = Math.floor(i / c.rowMax);
        const col = i % c.rowMax;
        const nInRow = Math.min(c.rowMax, civs.length - row * c.rowMax);
        const lateral = (col - (nInRow - 1) / 2) * c.lateralSpacing;
        const depth = Math.max(0, c.roleDepth.civilian - (s.depthOffset || 0)) +
          (h.squadTier || 0) * c.overflowTierDepth +
          row * c.rowSpacing + c.civilianExtraDepth;
        const p = slot(lateral, depth);
        const q = ZG.Geom.clampToWorld(p.x, p.y, h.radius);
        h.formationX = q.x;
        h.formationY = q.y;
      }
    }
  }

  function slotFor(state, h) {
    return { x: h.formationX, y: h.formationY };
  }
  function markDirty(state) { state.squadDirty = true; }

  ZG.Squads = { rebuild, update, slotFor, markDirty };
})();
```

```js
  if (!h || h.classId === 'shield') return 1;
  const g = ZG.Data.humans.shield.guard;
  for (const s of state.humans) {
    if (!s.alive || s.classId !== 'shield' || s.shield <= 0) continue;
    if (ZG.Geom.dist(s.x, s.y, ex, ey) > g.maxDist) continue;
    const toEx = Math.atan2(ey - s.y, ex - s.x);
    if (Math.abs(ZG.Geom.angleDiff(toEx, s.facing)) > g.facingHalfAngle * Math.PI / 180) continue;
    if (ZG.Geom.dist(s.x, s.y, h.x, h.y) > g.allyRadius) continue;
    const toAlly = Math.atan2(h.y - s.y, h.x - s.x);
    if (Math.abs(ZG.Geom.angleDiff(toAlly, s.facing + Math.PI)) >
        g.allyHalfAngle * Math.PI / 180) continue;
    if (ZG.Geom.dist(ex, ey, s.x, s.y) >= ZG.Geom.dist(ex, ey, h.x, h.y)) continue;
    return g.mul;
  }
  return 1;
}
```

```js
function interceptRay(state, x1, y1, x2, y2, opts) {
  const o = opts || {};
  const pad = o.pad === undefined ? 6 : o.pad;
  const half = (o.halfAngleDeg === undefined ? 60 : o.halfAngleDeg) * Math.PI / 180;
  let best = null, bestT = 1;
  for (const z of state.zombies) {
    if (!z.alive || z.typeId !== 'shield' || z.shield <= 0) continue;
    if (o.excludeId && z.id === o.excludeId) continue;
    const t = ZG.Geom.segmentCircleT(x1, y1, x2, y2, z.x, z.y,
      (z.radius || 10) + pad);
    if (t === null || t <= 0 || t >= bestT) continue;
    const toShooter = Math.atan2(y1 - z.y, x1 - z.x);
    if (Math.abs(ZG.Geom.angleDiff(toShooter, z.facing)) > half) continue;
    best = z; bestT = t;
  }
  return best;
}
```

```js
  const dx = hasSource ? fromX - target.x : 0;
  const dy = hasSource ? fromY - target.y : 0;
  const d = hasSource ? Math.hypot(dx, dy) : Infinity;
  const facing = hasSource
    ? Math.abs(ZG.Geom.angleDiff(Math.atan2(dy, dx), target.facing)) <= Math.PI / 3
    : true;

  if (target.kind === 'zombie' && target.typeId === 'shield') {
    const zd = ZG.Data.zombies.shield || {};
    const fireMul = zd.fireShieldMul || 2;
    const dmgMul = zd.shieldDamageMul === undefined ? 0.5 : zd.shieldDamageMul;
    if (target.shield <= 0) return { shieldDamage: 0, hpDamage: amount };
    if (damageKind === D.MELEE && d <= 40) return { shieldDamage: 0, hpDamage: amount };
    if (!facing) return { shieldDamage: 0, hpDamage: amount };
    if (damageKind === D.FIRE) {
      const shieldCost = amount * fireMul;
      if (target.shield >= shieldCost) {
        target.shield -= shieldCost;
        if (target.shield <= 0) onShieldBreak(target);
        return { shieldDamage: shieldCost, hpDamage: 0 };
      }
      const used = target.shield;
      target.shield = 0;
      const hpDamage = amount - used / fireMul;
      onShieldBreak(target);
      return { shieldDamage: used, hpDamage };
    }
    const eff = amount * dmgMul;
    const shieldDamage = Math.min(target.shield, eff);
    target.shield -= shieldDamage;
    const hpDamage = eff - shieldDamage;
    if (target.shield <= 0) onShieldBreak(target);
    return { shieldDamage, hpDamage };
  }

  if (target.kind === 'human' && target.shield > 0 && damageKind !== D.MELEE &&
      d > 40 && facing) {
    // 保留人类盾兵原有规则：近身（<40）绕过护盾
    let reduction = target.shieldReduction !== undefined ? target.shieldReduction : 0.4;
    if (damageKind === D.FIRE || damageKind === D.EXPLOSION) reduction *= 0.5;
    const eff = amount * (1 - reduction);
    const shieldDamage = Math.min(target.shield, eff);
    target.shield -= shieldDamage;
    const hpDamage = eff - shieldDamage;
    if (target.shield <= 0) {
      target.shield = 0;
      if (!target.shieldBroken) {
        target.shieldBroken = true;
        if (target.fallbackAttack) target.attack = Object.assign({}, target.fallbackAttack);
        target.role = 'rifle';
        target.squadDirty = true;
      }
    }
    return { shieldDamage, hpDamage };
  }

  return { shieldDamage: 0, hpDamage: amount };
}

function onShieldBreak(z) {
  z.permSlow = Math.max(z.permSlow || 0, 0.2);
  z.shieldBroken = true;
}
```

> 注意：`shieldFacing` 原来的「近身 <40 绕过」只保留在盾尸近战分支；人类分支保持原逻辑（近战直接走全额，因为 `damageKind!==D.MELEE` 才进护盾）。

```js
function fitWorldRect(cssW, cssH) {
  const scale = Math.min(cssW / W, cssH / H);
  return {
    scale,
    offsetX: (cssW - W * scale) / 2,
    offsetY: (cssH - H * scale) / 2,
    worldW: W * scale,
    worldH: H * scale
  };
}

function layoutStage() {
  const stage = document.getElementById('stage');
  if (!stage) return null;
  const vw = stage.clientWidth || window.innerWidth || 1280;
  const vh = stage.clientHeight || window.innerHeight || 720;
  const topEl = document.querySelector('.hud-top');
  const topH = topEl ? topEl.getBoundingClientRect().height : (vw < 900 ? 40 : 46);
  const portrait = vh > vw;
  const coarse = ZG.Platform.isMobile || matchMedia('(pointer: coarse)').matches;
  let panelH;
  if (coarse && portrait) panelH = Math.max(170, Math.min(250, vh * 0.30));
  else if (coarse) panelH = Math.max(120, Math.min(190, vh * 0.22));
  else panelH = Math.max(150, Math.min(210, vh * 0.207));
  const canvasH = Math.max(160, vh - topH - panelH);
  if (canvasH + topH + panelH > vh) panelH = Math.max(100, vh - topH - canvasH);
  stage.style.setProperty('--top-h', Math.round(topH) + 'px');
  stage.style.setProperty('--panel-h', Math.round(panelH) + 'px');
  stage.style.setProperty('--canvas-h', Math.round(canvasH) + 'px');
  return { cssW: vw, cssH: canvasH, topH, panelH };
}

function resize() {
  if (!R.ready) return;
  const geo = layoutStage();
  if (!geo) return;
  const cap = (ZG.Platform.quality && ZG.Platform.quality.dprCap) || 2;
  const dpr = Math.min(window.devicePixelRatio || 1, cap);
  const bw = Math.max(1, Math.round(geo.cssW * dpr));
  const bh = Math.max(1, Math.round(geo.cssH * dpr));
  for (const cv of [R.canvas, R.bg]) {
    if (!cv) continue;
    if (cv.width !== bw || cv.height !== bh) { cv.width = bw; cv.height = bh; }
  }
  const fit = fitWorldRect(geo.cssW, geo.cssH);
  R.dpr = dpr;
  R.cssW = geo.cssW;
  R.cssH = geo.cssH;
  R.worldScale = fit.scale;
  R.worldOffX = fit.offsetX;
  R.worldOffY = fit.offsetY;
  R.scale = fit.scale * dpr;
  R.offX = fit.offsetX * dpr;
  R.offY = fit.offsetY * dpr;
  R.bgSig = '';
}

function setTransform(ctx) {
  ctx.setTransform(R.scale, 0, 0, R.scale, R.offX, R.offY);
}

function worldRect() {
  return { scale: R.worldScale || 1, offsetX: R.worldOffX || 0, offsetY: R.worldOffY || 0 };
}
```

```js
function orientationPlan(o) {
  if (!o.portrait) return 'landscape';
  if (o.isMobile && o.supportsLock && o.fullscreenEnabled) return 'lock';
  return 'portrait';
}

function requestLandscape() {
  if (typeof document === 'undefined') return Promise.resolve({ ok: false, reason: 'no-dom' });
  const el = document.documentElement;
  if (!el.requestFullscreen) return Promise.resolve({ ok: false, reason: 'no-fullscreen' });
  return el.requestFullscreen().then(() => {
    try {
      if (screen.orientation && screen.orientation.lock) {
        return screen.orientation.lock('landscape')
          .then(() => ({ ok: true }))
          .catch(() => ({ ok: false, reason: 'lock' }));
      }
      return { ok: true };
    } catch (e) {
      return { ok: false, reason: 'lock' };
    }
  }).catch(() => ({ ok: false, reason: 'fullscreen' }));
}
```

## 7. 风险与回滚

| 风险 | 表现 | 缓解 |
|---|---|---|
| 阵位抖动/来回走 | 单位在阵位附近左右摇摆 | `arriveEps=8`；阵位按 id 稳定；保留原小队；`frontX/frontY` 重建不重置；测试 300 步哈希与位置 |
| 后排追不上盾线 | 远程/治疗落在最后 | `catchUpMul=1.35`、`catchUpDist=120`；阵位在盾后；单位速度高于盾线 |
| 全图搜索走太远 | 人类跑到边缘被四面夹击 | 搜索目标钳到 `searchStopInset=120`；接敌立即转 hold；多盾分散布置 |
| 流场重建太频繁 | 性能下降 | 15 步一次；建造/摧毁才立即重建；bench 监控 |
| 自由建墙围死 | 僵尸/人类卡死 | 墙上限 10；流场不可达格；8 秒传送兜底；不允许多建筑重叠 |
| 盾尸拦截过强 | 远程打不到后排 | 只有正面/有盾/最近的盾尸拦截；火焰/近战绕过；破盾失效；侧翼可打 |
| 火箭削弱过度 | 后期打不动巨人/BOSS | 直击仍 100% + 攻城 1.25；溅射 50% 清群；bot 验证 |
| iOS 无法锁定横屏 | 仍竖屏 | 竖屏自适应可玩；提示条 + 全屏按钮；不阻断 |
| 存档兼容 | 旧 localStorage 设置字段 | 只存设置/最佳回合；新增字段用默认值；`applySavedSettings` 忽略未知键 |
| PWA 缓存旧代码 | 更新后仍加载旧文件 | `CACHE='zd-v1.2.0'`；`skipWaiting`/`clients.claim`；刷新提示 |
| 重建小队导致目标抖动 | 每秒换目标 | 保留原小队；目标选择按 id 稳定；同一 zombie 被选走才换 |
| 建筑矩形/中心换算错误 | 放墙偏一半、碰撞错位 | 全项目统一 `Geom` 左上角约定；所有建筑走 `rectOfBuilding`；测试覆盖 |
| 手机 tooltip/指针偏移 | 点不到单位 | `worldRect()` 单点映射；`toWorld` 越界返回 null；手验矩阵 |

回滚：

- 每个 Task 独立提交；若 AI 编队导致不可玩，可先回滚 Task 6 的 `squads.js` 接入，保留自由放置/数值/移动端改动。
- 数值改动集中在 data 文件，可单独回滚。
- 若 Task 8 拦截导致平衡崩坏，可先关闭 `intercept`（数据字段置 false）而不回滚代码。
