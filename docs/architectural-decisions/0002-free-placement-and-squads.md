# ADR-0002：去部署区 + 人类小队制 + 自由建筑

- **状态**：已采纳（2026-10-19）
- **决策者**：用户 + 实现会话
- **关联计划**：`docs/superpowers/plans/2026-10-19-v1.2-ai-layout-rebalance.md`、`2026-10-19-v1.2-detailed-implementation.md`

## 背景

v1.1 的运行时依赖三个固定概念：`map.deploy`（部署区）、`map.slots`（建筑槽位）、`map.spawns`（固定出生点）。玩家只能把人类放进部署区、把建筑放进槽位，僵尸只从 2–3 个点出现；战斗中人类以 `homeX/homeY` 为锚点，没有目标就回原位，形成“站桩”观感。同时固定槽位让“自由摆放/围墙迷宫”无法实现，固定出生点让四面来袭与动态流场失效。

## 决策

1. **删除 `deploy / slots / spawns` 三个运行时概念**。世界边界 + 障碍/建筑碰撞 + 世界坐标放置取代它们。
2. **人类放置**：`[radius+4, W-radius-4]` 内任意合法位置；与人类/建筑/障碍不重叠。
3. **建筑放置**：自由坐标 + 形状（圆/矩形）+ 每种数量上限；围墙 64×24 可横竖切换、仅阻挡不减速；摧毁/拆除立即释放名额。
4. **僵尸出生**：四边屏幕外 10–60px 环形出生，保留 1 秒传送门预警。
5. **寻路**：流场以存活人类为多源 BFS 源点，战斗中每 15 步重建；无人类时指向地图中心。
6. **人类 AI**：新增 `src/sim/squads.js`（纯模拟、无 DOM、无随机）。以盾兵为核心的小队制：盾线在前、远程/治疗分层在后；无敌人时向最近待出生边缘搜索并在距边界 120px 处停住；闪避/寻医结束后归队，不回原始放置点。
7. **过渡顺序**：Task 3 删 slots → Task 4 删 spawns → Task 5 删 deploy，保证每个提交 `npm test` 全绿、可单独回滚。

## 后果

- **正面**：放置自由度、四面压力、小队结阵与盾线观感；建筑上限阻止“全图堆满”；移动端可全屏居中。
- **代价**：AI 复杂度与每步成本上升；流场每 15 步重建带来额外 CPU（仍在 2.5ms/步预算内）；固定槽位的“废墟/槽位”逻辑被移除，旧存档与旧测试需迁移。
- **确定性**：编队重建与目标选择显式按 `id` 决胜；所有计时用固定步计数，不用墙钟。

## 备选与取舍

| 方案 | 拒绝原因 |
|---|---|
| 保留部署区，只扩大范围 | 仍无法全图摆放，且与“僵尸四面来袭”冲突 |
| 英雄式单体 AI（每人独立寻敌） | 无盾线、后排容易乱跑，无法满足“盾兵在前”的用户要求 |
| 用完整 A* 替代流场 | 300 僵尸时成本过高；多源 BFS 足够 |
| 保留槽位并允许自由放置双轨 | 双写状态、废墟语义冲突，测试无法收敛 |
