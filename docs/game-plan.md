## 1. 游戏定位与核心体验

### 1.1 一句话

> 在固定部署区招募并摆放人类小队，抵挡从固定出生点涌来的僵尸；用击杀收入扩军、建建筑、升科技，尽可能活过更多回合。

### 1.2 核心体验

游戏不追求“手速”，追求的是**战前判断**与**战场阅读**。每一回合玩家只做五类决策：补什么兵、放在哪里、建什么、升哪条科技、留多少钱。开战之后，玩家看的是自己布阵的结果。

五个体验支柱：

1. **布阵的取舍**  
   固定部署区、有限人口、有限建筑槽位。每个单位都有明确职责，没有一套阵容能同时解决所有僵尸。

2. **可读的混乱**  
   同屏最多 300 只僵尸。颜色、圆形描边、职业符号、血条、护盾弧、感染环、BOSS 预警圈共同保证玩家能看懂“哪里要崩了”。

3. **滚雪球与止血**  
   击杀 → 收入 → 扩军 → 更强，这是正循环；战损 → 补员 → 经济被吃掉，这是负循环。无尽模式的乐趣在于判断什么时候该投资、什么时候该止血。

4. **随机惊喜**  
   每 3 回合随机晋升 3 名队长，每 7 回合随机赠送 1 名英雄。同一套基础阵容，每局会长成不同的样子。

5. **无尽挑战**  
   20 回合算入门，40 回合算通关级。之后僵尸 HP 与 BOSS 血量继续指数成长，最终形成一堵玩家不可能永远越过的墙。

### 1.3 目标玩家与平台

- **目标玩家**：喜欢塔防、自走棋、自动战斗、僵尸生存的玩家；接受“看战斗、做决策”，不要求动作操作。
- **平台**：桌面浏览器 + 手机浏览器；桌面鼠标为主，手机横屏触控；PWA/桌面打包/Steam 路线见第 13 章。
- **语言**：简体中文。
- **单局时长**：一局 20 回合约 20–30 分钟；40 回合约 45–70 分钟（含整备期与加速）。
- **运行方式**：双击 `index.html` 即玩，零依赖、零构建、零外部素材。

### 1.4 成功标准与非目标

**成功标准**

- 新玩家 10 分钟内理解核心循环。
- 20 回合是“入门线”，40 回合是“通关级”，需要合理的兵种搭配、站位、建筑与科技。
- 同屏 300 僵尸 + 80 人口 + 特效，稳定 60 FPS。
- 每一回合至少有一个“值得想一下”的决策；不存在无脑堆一种兵就能稳定过 40 回合的解法。
- 每种僵尸都有明确的克制手段；每个职业都有至少一个高光场景。

**非目标（首版不做）**

- 不做玩家直接操控单位（不是双摇杆射击）。
- 不做多人联机 / 合作 / PVP。
- 不做自由建造、迷宫围墙、高低差、复杂地形。
- 不做剧情战役、关卡叙事、过场动画。
- 不做付费、广告、账号系统、在线排行榜；首版只做本地最佳回合。
- 不做独立的 iOS/Android 原生 App（首版用 PWA/手机浏览器；Capacitor 留到后期）。
- 不做竖屏手机 UI；手机端横屏游玩，竖屏仅提示。

## 2. 核心循环与回合流程

### 2.1 大循环

```
选图
  ↓
初始整备（400 金：招募 / 布阵 / 建造 / 升科技）
  ↓
开始回合 → 僵尸分批从固定出生点进攻
  ↓
人类自动索敌 / 攻击；击杀得钱
  ↓
清空本回合（出生队列空 + 场上僵尸 0 + 3 秒感染结算）
  ↓
结算（回血 30% / 感染隔离 / 平民收入 / 通关奖励）
  ↓
队长晋升（每 3 回合）/ BOSS 英雄奖励（每 7 回合）
  ↓
整备期 → 下一回合（难度递增）
  ↑__________________________|
```

人类全灭 → 1 秒死亡确认 → 游戏结束。

### 2.2 阶段表

| 阶段 | 玩家能做什么 | 玩家不能做什么 | 退出条件 |
|---|---|---|---|
| 选图 | 选择 3 张地图之一，查看难度与最佳回合 | — | 点击“开始” |
| 整备期 | 招募、拖拽摆放、出售、建造、拆建筑、升科技、查看下一波预览 | 不能开始战斗以外的操作 | 点击“开始回合” |
| 战斗期 | 暂停 / 1x / 2x / 3x；查看单位信息 | 招募、建造、升级、拖动单位、指定集火 | 清场或人类全灭 |
| 结算 | 查看收入明细、队长晋升、英雄奖励 | — | 点击“进入整备” |
| 游戏结束 | 查看统计、重开、回选图 | — | 重开或退出 |

### 2.3 整备期规则

- **首次整备**：进入地图后立即获得 400 金，人口上限 10。
- **招募**：点击兵种卡 → 在部署区内点击放置。放置时显示射程圈、碰撞半径、是否合法。
- **拖动**：整备期内可免费拖动已有人类，重新调整站位；不能拖出部署区。
- **出售**：选中单位 → 出售，返还 50% 造价；最后一名人类不能出售（防止自杀式空场）。
- **建造**：点击建筑卡 → 点击空建筑槽位；每个槽位 1 座建筑（地雷阵/减速陷阱也占槽）。
- **拆除**：整备期可拆除建筑，返还 50% 造价；被摧毁的废墟不返还。
- **科技**：四条科技线，随时购买，立即生效；购买后不能退款。
- **下一波预览**：显示僵尸总数、各类型数量、是否有 BOSS、预计解锁的新类型。
- **开始回合**：点击后锁定布阵，进入战斗。若场上没有人类，按钮禁用并提示。

### 2.4 战斗期规则

- 僵尸按“出生队列”分批出现，每批 6–12 只，间隔 5–8 秒；出生点提前 1 秒显示传送门预警。
- 玩家只能暂停 / 1x / 2x / 3x。加速只加快模拟，不改变任何数值。
- 人类在战斗中自主移动：会离开部署区追击、受伤后寻医、闪避狂尸冲刺；玩家不能直接操控，但可以用站位/建筑/兵种组合影响其行为。
- 战斗中不弹广告、不弹选择框；BOSS 出现、英雄奖励、队长晋升都用非阻塞横幅提示。
- 玩家可以悬停单位查看血量、感染、护盾、DPS、状态；不能点击下达命令。
- 战斗中可以打开“设置/帮助”面板，打开时自动暂停。

### 2.5 结算规则

清场后依次结算：

1. **存活人类回血**：回复 30% 最大生命（不超过上限）；感染不因此减少。
2. **感染隔离**：所有感染值压到 30 以下；若场上有治疗兵/疫医，整备期自动清零。
3. **平民收入**：每个存活平民 +12 金。
4. **通关奖励**：`60 + 12 × 回合数` 金。
5. **队长晋升**：回合数为 3 的倍数时，晋升最多 3 名队长。
6. **BOSS 英雄奖励**：BOSS 在战斗中被击杀时已立即发放，不等到结算。
7. **建筑状态**：地雷阵重新布置；护盾/护甲恢复；废墟槽位在本回合结算后解锁。
8. **进入整备期**：显示收入明细与下一波预览。

### 2.6 失败判定

- 人类数量为 0 → 进入 1 秒死亡确认 → 确认后游戏结束。
- 同帧人类全灭且最后一只僵尸死亡 → 判负（人类全灭优先）。
- 英雄阵亡不算人类全灭（会重伤休整），但若英雄是最后一名人类，仍判负。
- 转化手枪兵在存活期间算人类；到期消失若导致人类为 0，判负。

### 2.7 回合时间轴

```
整备期（不限时）
  │ 点击开始
  ▼
0s ── 出生点预警 1s
5s ── 第一批僵尸
...
每 5–8s 一批
...
BOSS 回合：BOSS 在中段出现，带 20% 护卫
...
出生队列空 + 场上僵尸 0
  │ 3s 感染结算
  ▼
结算（约 1–3s 动画）→ 整备期
```

### 2.8 反卡死与超时

- 僵尸 8 秒没有位置进展 → 传送到最近可达格。
- 回合进行 180 秒后，每 30 秒全体僵尸 +30% 速度与伤害（狂暴）。
- 回合进行 240 秒 → 强制结算：剩余僵尸全部死亡，已获得的击杀奖励保留，不额外发奖励。
- 任何情况下不允许回合无限持续。

## 3. 玩家操作与界面

### 3.1 操作总表

| 输入 | 作用 |
|---|---|
| 鼠标左键 | 选卡、放置、选中单位、点击按钮 |
| 鼠标右键 / Esc | 取消当前选卡或放置 |
| 鼠标悬停 | 显示单位/建筑/僵尸的详细信息 |
| 拖动已有人类 | 整备期内免费重新站位 |
| 空格 | 暂停 / 继续 |
| 1 / 2 / 3 | 1x / 2x / 3x 速度 |
| Tab | 切换“招募 / 建筑 / 科技”面板 |
| M | 静音开关 |
| H | 帮助/图鉴 |

手机端：点按 = 左键，拖动 = 拖动已有人类；信息用点按显示，不依赖悬停。详见第 13.3.3 节。

### 3.2 屏幕结构

```
┌──────────────────────────────────────────────────────────────┐
│ 回合 7   金钱 1,250   人口 22/22   僵尸 34    [1x][2x][3x][暂停] │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                        战 场（Canvas）                        │
│                     1280 × 720 逻辑分辨率                     │
│                                                              │
│   部署区高亮 / 建筑槽位虚线 / 出生点传送门 / BOSS 血条          │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ [招募] [建筑] [科技]                                           │
│ 手枪60  霰弹90  机枪140  喷火130  导弹180  盾兵100  治疗120 ... │
│ 下一波：普通×30 狂尸×8 盾尸×4 爆尸×3 母体×1        [开始回合]  │
└──────────────────────────────────────────────────────────────┘
```

- 战场用 Canvas 绘制；HUD、商店、科技、弹窗用 DOM 叠层，保证文字清晰。
- 整备期底部面板展开；战斗期收起为一条窄栏，只保留回合/金钱/人口/剩余僵尸/速度。
- 所有面板支持鼠标滚轮与点击，不依赖拖拽滚动。

### 3.3 整备期面板

**招募页**

- 8 张兵种卡：名称、造价、HP、DPS、射程、一句话定位、当前可买数量。
- 卡片不可买时变灰并显示原因（金钱不足 / 人口已满 / 平民上限）。
- 点击卡片后进入放置模式；部署区内显示绿色/红色预览圈。
- 放置后若金钱仍够，保持该卡片选中，方便连续放多个；Esc 退出。

**建筑页**

- 6 张建筑卡：造价、HP、效果、占用槽位。
- 点击卡片后，所有空槽位高亮；点击槽位建造。
- 空槽位显示虚线圆/方框；已有建筑显示图标、血条、光环范围（悬停时）。

**科技页**

- 四条科技线：火力、护甲、经济、血清。
- 每行显示：当前等级、当前效果、下一级费用、下一级效果、购买按钮。
- 满级显示“已满级”。

### 3.4 战斗期 HUD

- 顶部：回合数、金钱、人口、存活人类、剩余僵尸、BOSS 血条（如有）、速度按钮、暂停。
- 单位上方：血条（仅受伤时显示）、感染条（感染时显示）、护盾条（有盾时显示）、队长金环、英雄星标。
- 屏幕边缘：当僵尸从屏幕外/边缘出生时，显示红色方向箭头与数量。
- 底部：战斗日志（可选）——“队长晋升”“BOSS 出现”“建筑被摧毁”“英雄重伤”等。

### 3.5 信息与提示

- 悬停人类：名称、等级（普通/队长/英雄）、HP、DPS、射程、感染值、状态、当前目标。
- 悬停僵尸：名称、HP、护盾、速度、伤害、赏金、特殊技能、当前目标。
- 悬停建筑：名称、HP、效果范围、是否被围攻。
- 悬停科技/兵种卡：完整 tooltip，包含“克制什么 / 被什么克制”。

### 3.6 新手引导

- 首次进入郊区公路时，用 4 步高亮提示：
  1. 点击手枪兵卡，在部署区放一个。
  2. 点击开始回合，看第一波。
  3. 结算后用金币补 2 个兵。
  4. 介绍建筑槽位与科技。
- 引导只出现一次，可在设置里重播。
- 第一回合只出普通丧尸，确保新手能赢。

### 3.7 玩家每回合的 5 个决策

1. **补什么兵**：前排够不够？输出够不够？治疗够不够？要不要补平民？
2. **放在哪里**：盾兵堵口？远程覆盖？治疗站后排？武士放侧翼？
3. **建什么**：路障改道？哨塔补输出？医疗站续航？弹药库增伤？
4. **升哪条科技**：火力/护甲/经济/血清，钱只够一条时怎么选？
5. **留多少钱**：全花掉换战力，还是留钱应对下一波/补员？

### 3.8 可访问性

- 颜色之外还有汉字/符号、描边、血条、形状差异，色弱玩家也能区分。
- 伤害数字可关闭；屏幕震动可关闭；可暂停。
- 所有文字使用高对比度；最小字号 12px；关键数字加粗。
- 不依赖快速反应；所有操作都可以慢慢做。

## 4. 人类单位

### 4.0 设计原则

- 每个单位有一个**明确职责**，不是一个“数值更大”的替代品。
- 每个单位都有**克制对象**和**被克制对象**。
- 价格、人口、射程、站位共同构成取舍；没有全能兵。
- 自动战斗下，单位的 AI 必须“可读”：玩家能预判它会打谁、为什么打不过。

### 4.1 人类总表

| 单位 | 造价 | HP | DPS | 射程 | 半径 | 定位 |
|---|---:|---:|---:|---:|---:|---|
| 手枪兵 | 60 | 140 | 24 | 200 | 8 | 均衡基础兵 |
| 霰弹兵 | 90 | 180 | 50（近） | 120（180 外衰减 50%） | 9 | 近身清群 |
| 机枪兵 | 140 | 220 | 58（含换弹） | 240 | 9 | 持续单体输出 |
| 喷火兵 | 130 | 200 | 40 + 灼烧 15 | 100（50° 锥） | 9 | 范围清群/穿透 |
| 导弹兵 | 180 | 160 | 65（对攻城 +25%） | 330 | 9 | 反大型/反集群 |
| 盾兵 | 100 | 500 | 12 | 50 | 11 | 前排坦克/嘲讽 |
| 治疗兵 | 120 | 150 | 8 | 160 | 8 | 治疗/驱散感染 |
| 平民 | 40 | 80 | 0 | 0 | 7 | 经济单位 |

**人口上限**：`min(80, 8 + 2 × 回合数)`。

- 英雄不占人口。
- 疫医转化来的手枪兵不占人口，但 3 个完整回合后消失，同时最多 15 名。
- 平民最多 8 个。
- 人口显示格式：`人口 22/22（英雄 1）`。

### 4.2 八职业详解

#### 手枪兵（Pistol）

- **定位**：基础通用输出，前期撑场面，后期补人口/吸引火力。
- **数值**：60 金 / 140 HP / 12 伤害 × 2 发/秒 = 24 DPS / 200 射程 / r8。
- **攻击**：单体快速射击，优先最近目标。
- **克制**：普通丧尸、狂尸（前期）；落单的爆尸。
- **被克制**：盾尸正面盾、巨人高血、爆尸近身爆炸。
- **使用建议**：前 3 回合买 4–6 个；中后期不要全卖，留几个放在后排吸引狂尸/爆尸。

#### 霰弹兵（Shotgun）

- **定位**：近身爆发、清群、反爆尸。
- **数值**：90 金 / 180 HP / 5 弹丸 × 10 伤害 = 50/发，1 发/秒；120 射程内全额，180 外衰减 50% / r9。
- **攻击**：扇形 5 弹丸，优先扇形内目标密度最高处。
- **克制**：普通群、狂尸、爆尸（近距离秒杀）、盾尸侧后。
- **被克制**：巨人、母体、远程 BOSS；需要前排保护。
- **使用建议**：放在拐角/入口内侧；2–3 个即可，不要当主力远程。

#### 机枪兵（Machine Gunner）

- **定位**：持续单体输出，中排主力。
- **数值**：140 金 / 220 HP / 9 伤害 × 9 发/秒 = 81 理论 DPS；45 发弹匣，2 秒换弹，综合约 58 DPS / 240 射程 / r9。
- **攻击**：持续扫射，优先最近目标；换弹时停火 2 秒。
- **克制**：普通、狂尸、母体（持续输出）、盾尸侧后。
- **被克制**：巨人（高血+拆前排）、爆尸（近身）、BOSS 石块。
- **使用建议**：中排主力，4–6 个；放在弹药库光环内；用盾兵保护换弹窗口。

#### 喷火兵（Flamethrower）

- **定位**：范围清群、穿透、灼烧压制。
- **数值**：130 金 / 200 HP / 5 伤害 × 8 跳/秒 = 40 DPS（可命中锥内多个目标）+ 灼烧 5/秒 × 3 秒 / 100 射程 / 50° 锥 / r9。
- **攻击**：锥形持续判定，穿透所有目标；优先密度最高处。
- **克制**：普通群、狂尸群、母体幼体、盾尸（火焰只吃 50% 盾减伤）。
- **被克制**：巨人、远程 BOSS、爆尸（自爆）。
- **使用建议**：放在前排/拐角，配合减速陷阱与路障；2–4 个足够，太多会缺单体爆发。

#### 导弹兵（Rocket）

- **定位**：反大型、反集群、拆盾。
- **数值**：180 金 / 160 HP / 130 伤害 × 0.5 发/秒 = 65 单体 DPS；60 溅射；对攻城单位 +25% ≈ 81 / 330 射程 / r9。
- **攻击**：慢速火箭，落点爆炸；优先最大集群；场上有巨人/母体/BOSS 时优先攻城单位。
- **克制**：巨人、母体、盾尸（爆炸 50% 穿盾）、BOSS、密集群。
- **被克制**：狂尸快速接近、爆尸近身、高机动目标。
- **使用建议**：后排 2–3 个；优先升火力科技；不要放在最前线。

#### 盾兵（Shield）

- **定位**：前排坦克、堵口、嘲讽保护后排。
- **数值**：100 金 / 500 HP + 250 正面盾 / 12 DPS / 50 射程 / r11。
- **攻击**：不主动索敌；近身反击；90 半径内僵尸优先攻击盾兵（嘲讽）。
- **克制**：普通/狂尸（挡路、吸怪）、保护治疗/导弹。
- **被克制**：巨人（高伤/拆建筑）、爆尸（爆炸）、母体（高血）。
- **使用建议**：每个入口 1–2 个；放在治疗兵与医疗站范围内；不要指望它输出。

#### 治疗兵（Medic）

- **定位**：续航、驱散感染、让前排站得住。
- **数值**：120 金 / 150 HP / 8 DPS 自卫 / 160 射程 / r8；治疗 20 HP/s；血清 3 次/回合，每次驱散 50 感染，8 秒冷却。
- **攻击**：优先治疗感染 ≥50 的友军，其次血量百分比最低；无感染时治疗前排。
- **克制**：感染、持续伤害、消耗战。
- **被克制**：狂尸/爆尸切后排、BOSS 石块、AOE。
- **使用建议**：2–3 个，放在盾兵后方；和医疗站叠加；不要让治疗兵站最前排。

#### 平民（Civilian）

- **定位**：经济投资，用前期金钱换后期收入。
- **数值**：40 金 / 80 HP / 不攻击 / r7；每回合结算 +12 金；上限 8 个。
- **攻击**：无；会感染、会死亡、会变丧尸。
- **克制**：经济；越早买越回本（约 3.3 回合回本）。
- **被克制**：所有僵尸；尤其怕狂尸/爆尸切后排。
- **使用建议**：前 3 回合买 3–5 个；后期补满 8 个；放在最安全的位置，不要放在前线。

### 4.3 队长

**晋升时机**：每 3 回合（R3、R6、R9…）结算时，最多晋升 3 名。

**候选规则**：

- 只从存活、未晋升、非英雄、非平民的**战斗职业**中选。
- 尽量选 3 个不同职业；职业不足时从剩余候选中补。
- 候选不足 3 名时，晋升所有候选；剩余名额转为“全体队长伤害 +10%”的溢出奖励。

**晋升效果**：

- 最大生命 ×2.5，当前生命同步 ×2.5。
- 伤害 ×1.3。
- 攻击速度 ×1.4（治疗兵的治疗频率同样提升）。
- 免疫感染；晋升时清除已有感染。
- 金色光环 + 队长标记。

**死亡**：

- 不转化为丧尸。
- 半径 90 爆炸，对僵尸造成 `120 + 15% 目标最大生命` 伤害。
- 对 BOSS 的百分比部分按固定上限 800 结算，防止献祭队长秒 BOSS。
- 爆炸只伤僵尸，不伤人类/建筑。

**上限**：

- 最多 8 名队长。
- 超过 8 名后，新晋升名额改为全体队长伤害 +10%，最多 +50%。
- 队长死亡后名额空出，下次晋升可以补上。

### 4.5 英雄详解

#### 长官（Officer）

- **定位**：后排持续输出 + 每回合一次清场导弹。
- **数值**：1200 HP / r10 / 双枪 2×18 伤害每 0.35 秒 ≈ 103 DPS / 300 射程。
- **导弹支援**：每回合自动触发一次，优先选择 8+ 僵尸的集群或 BOSS；3 发导弹，每发 400 伤害、半径 140，间隔 0.4 秒。
- **AI**：站在后排，优先最近/高威胁目标；导弹在“收益最大”时自动释放，不需要玩家操作。
- **克制**：密集群、BOSS、巨人/母体。
- **被克制**：狂尸/爆尸切后排、BOSS 石块。
- **使用建议**：放在治疗兵与盾兵的保护圈内；导弹留给 BOSS 波或高密度波。

#### 武士（Samurai）

- **定位**：近战高爆发、切盾尸/狂尸、剑气穿透。
- **数值**：1100 HP / r11 / 126 伤害每 0.7 秒 ≈ 180 DPS / 45 射程 / 移动速度 70。
- **剑气**：每次攻击 25% 概率触发，沿正面直线 320×80，300 伤害，穿透所有目标。
- **AI**：敌人进入 180 半径时突进到近战范围；没有敌人时回到原位。
- **克制**：盾尸（近战绕过正面盾）、狂尸、母体、密集直线群。
- **被克制**：爆尸（自爆）、巨人（高伤）、远程 BOSS 石块。
- **使用建议**：放在侧翼/入口，不要放在正中央被集火；配合治疗兵。

#### 加特林士兵（Gatling）

- **定位**：高血量持续输出 + 团队攻速光环。
- **数值**：1600 HP / r14（体型更大）/ 22 伤害 × 10 发/秒 = 220 DPS / 260 射程；1 秒转管预热。
- **鼓舞**：每 45 秒自动触发，半径 200 内友军 +30% 攻速，持续 8 秒。
- **AI**：优先最近目标；鼓舞在周围友军 ≥3 时自动触发（否则延后）。
- **克制**：普通/狂尸/母体/巨人（持续输出）。
- **被克制**：爆尸近身、BOSS 石块；体型大，容易被集火。
- **使用建议**：放在中排，周围多放机枪/手枪/霰弹，让鼓舞收益最大化。

#### 疫医（Plague Doctor）

- **定位**：治疗 + 群体治疗 + 感染控制 + 转化丧尸。
- **数值**：800 HP / r8 / 药瓶 29 伤害 × 1.2 发/秒 ≈ 35 DPS，溅射半径 50 / 230 射程。
- **治疗**：单体 35 HP/s；驱散 80 感染/8 秒。
- **群体治疗**：每 12 秒自动向友军最密集处投掷治疗药剂，半径 180，全体友军 +70 HP、驱散 30 感染；可被血清科技提升。
- **转化**：攻击命中非 BOSS 丧尸时 15% 概率将其转化为手枪兵；每回合最多 5 个。
- **AI**：优先治疗感染 ≥40 或血量最低的友军；没有治疗目标时攻击最近的僵尸；群体治疗在 3+ 友军受伤时释放。
- **克制**：感染、消耗战、母体（转化可阻止爆仔）、爆尸（远程点杀）。
- **被克制**：高爆发单体、BOSS 石块、狂尸突脸。
- **使用建议**：放在后排中央，保证群体治疗覆盖前排；转化兵当免费肉盾/输出，不要当核心。

**疫医转化兵**

- 属性同普通手枪兵（140 HP、24 DPS、200 射程、r8），享受科技/光环。
- **不占人口**。
- 转化当回合算第 1 回合，服务 3 个完整回合后，在第 3 回合结算时自动消失。
- 消失时不转化为丧尸；到期前死亡仍按普通人类规则变成丧尸。
- 不参与队长晋升。
- 同时最多 15 名（5 个/回合 × 3 回合）。
- 转化母体/爆尸时，阻止其死亡效果（不爆仔、不爆炸）。

### 5.2 僵尸详解

#### 普通丧尸（Walker）

- **定位**：基础杂兵，数量压力。
- **行为**：沿流场走向部署区，优先最近人类；近战攻击。
- **感染**：每次命中 30% 概率 +20 感染。
- **克制**：霰弹、喷火、机枪、任何 AOE。
- **威胁**：单体低，但数量多；后期 HP 成长后成为“血墙”。

#### 狂尸（Runner）

- **定位**：快速突进、切后排。
- **行为**：每 4 秒冲刺 0.8 秒，速度 150；优先最近人类，但会绕过慢速僵尸。
- **感染**：25% 概率 +18。
- **克制**：霰弹、喷火、减速陷阱、盾兵嘲讽。
- **威胁**：治疗兵、导弹兵、平民；必须用前排/减速保护后排。

#### 盾尸（Shield Zombie）

- **定位**：正面免伤推进，逼玩家绕后/用 AOE。
- **行为**：正面 120° 盾，200 盾值；朝向当前目标；远程伤害减免 70%，先扣盾；盾破后减速 20%。
- **弱点**：近战 <40 绕过盾；火焰/爆炸只吃 50% 减伤；侧后全额。
- **克制**：导弹、喷火、武士、霰弹侧后。
- **威胁**：低 DPS 的正面防线；逼玩家分散站位。

#### 爆尸（Boomer）

- **定位**：反集群、逼玩家分散/点杀。
- **行为**：优先冲向人类最密集处；距离 ≤35 或 HP ≤20% 时点燃 0.8 秒引信；期间被击杀则取消爆炸。
- **爆炸**：半径 80，70 伤害，+100 感染；不伤建筑。
- **克制**：霰弹近距离秒杀、导弹远程点杀、减速陷阱。
- **威胁**：扎堆的治疗兵/平民/远程；一次爆炸可能直接打乱防线。

#### 母体（Mother）

- **定位**：持续产仔、拆建筑、消耗战。
- **行为**：缓慢走向部署区；优先拆挡路建筑；死亡时爆出 3–5 只幼体，并半径 120 爆炸（建筑 200、人类 80）。
- **幼体**：40 HP、55 速度、4 伤害、25% 概率 +15 感染；单波全局上限 30。
- **克制**：导弹、长官导弹、疫医转化（阻止爆仔）、喷火清幼体。
- **威胁**：建筑、防线续航；如果放着不管，幼体会滚雪球。

#### 巨人（Giant）

- **定位**：攻城坦克、拆建筑、吸收火力。
- **行为**：极慢；优先攻击 220 内挡路建筑，否则攻击最近人类；对建筑伤害 ×3；击退免疫。
- **克制**：导弹（+25%）、长官导弹、武士、机枪集火。
- **威胁**：路障/哨塔/医疗站；必须在其到达前集中火力。

#### 幼体（Baby）

- **定位**：母体死亡后的数量压力。
- **行为**：快速冲向最近人类；不再爆仔。
- **克制**：喷火、霰弹、机枪。
- **威胁**：如果母体死在防线内，幼体会直接贴脸。

#### 转化丧尸（Turned Zombie）

- **定位**：人类死亡后的惩罚。
- **数值**：当回合普通丧尸 HP 的 50%；赏金 0；计入本回合剩余僵尸。
- **行为**：同普通丧尸。
- **注意**：不要让人类死在防线内部，否则会立刻变成一只贴脸僵尸。

### 5.3 波次构成与解锁

**每回合数量**：`N = 6 + 5 × R`。

| 回合 | 数量 | 构成 |
|---|---:|---|
| R1–2 | 11 / 16 | 普通 100% |
| R3 | 21 | 普通 85% / 狂尸 15% |
| R4 | 26 | 普通 68% / 狂尸 15% / 盾尸 9% / 爆尸 8% |
| R5 | 31 | 普通 55% / 狂尸 16% / 盾尸 11% / 爆尸 10% / 母体 8% |
| R6+ | 36+ | 普通 45% / 狂尸 17% / 盾尸 13% / 爆尸 12% / 母体 8% / 巨人 5% |
| R10 后 | — | 每 5 回合从“普通”移 2% 给精英；普通最低 30% |
| BOSS 回合 | +20% | 额外护卫，构成为当回合比例 |

**示例**：R7 普通数量 41，BOSS 护卫 +8，共 49 只 + BOSS 1 只。

### 5.4 BOSS 坦克

- **出现**：R7、R14、R21…每 7 回合；带 20% 当波数量的护卫。
- **HP**：`1200 × 1.14^(R-1)`。
- **石块**：每 4 秒瞄准人类最密集处；2.0 秒红圈预警；半径 70；伤害 `80 + 6R`；+30 感染。
- **自动侧移**：非盾人类在落点锁定前 0.4 秒自动侧移 60px（120 速度）；盾兵不能躲，用盾硬吃；侧移不会离开部署区。
- **近身践踏**：半径 60，80 伤害，1.5 秒一次。
- **击杀奖励**：`400 + 50R` 金 + 随机英雄。
- **建筑**：BOSS 石块不伤建筑；对建筑的威胁由同波护卫里的巨人/母体承担。
- **战术**：
  - 分散站位，减少石块一次砸中多人。
  - 盾兵放在落点附近硬吃，保护治疗/导弹。
  - 长官导弹留给 BOSS 或高密度护卫。
  - 武士可以贴身输出，但注意践踏。
  - 疫医转化护卫，减少 BOSS 周围数量。

### 5.5 僵尸威胁矩阵

| 僵尸 | 主要威胁对象 | 玩家应对 |
|---|---|---|
| 普通 | 前排、经济单位 | 前排 + AOE |
| 狂尸 | 后排、治疗、平民 | 嘲讽、减速、霰弹 |
| 盾尸 | 低 DPS 正面防线 | 导弹、火焰、侧后 |
| 爆尸 | 扎堆单位 | 分散、点杀、减速 |
| 母体 | 建筑、续航 | 导弹、转化、AOE |
| 巨人 | 建筑、前排 | 导弹、长官、武士 |
| 幼体 | 防线内部 | 喷火、霰弹 |
| BOSS | 集群、治疗 | 分散、盾兵、导弹 |

## 6. 特殊机制

### 6.1 感染

**感染值**：0–100。

**来源**：

| 来源 | 概率 / 数值 |
|---|---|
| 普通丧尸近战 | 30% 概率 +20 |
| 狂尸近战 | 25% 概率 +18 |
| 盾尸近战 | 35% 概率 +25 |
| 母体近战 | 40% 概率 +30 |
| 巨人近战 | 50% 概率 +40 |
| 幼体近战 | 25% 概率 +15 |
| 爆尸爆炸 | 范围内 +100 |
| BOSS 石块 | 100% +30 |

**持续伤害**：`每秒损失 = 最大生命 × 0.0002 × 感染值`。100 感染 = 2%/秒；50 感染 = 1%/秒。

**治疗**：

- 治疗兵：自动治疗感染 ≥50 的友军；每次驱散 50，8 秒冷却，每回合 3 次血清；血清不花金币。
- 疫医：驱散 80/8 秒；群体治疗额外驱散 30。
- 医疗站：半径 200 内感染 -1/秒；范围内治疗兵血清 +1。
- 血清科技：每级 +1 血清、治疗量 +5%。
- **主动寻医**：HP 低于 60% 或感染达到 30 的单位会自行前往最近的医疗站或治疗兵；治疗兵也会主动迎向伤员。感染值低于 50 且场上有医疗站时优先去医疗站，感染 ≥50 时优先找还有血清/驱散能力的治疗兵或疫医。

**回合结束**：

- 所有存活人类感染值压到 30 以下（隔离）。
- 整备期有治疗兵/疫医时自动清零。
- 没有治疗兵/疫医时，30 点感染带入下一回合；下一场战斗继续掉血。

**规则**：

- 感染不传播给其他人类。
- 感染不会直接致死；HP 归零才死。
- 感染死亡与普通死亡一样变丧尸。
- 队长/英雄免疫感染；晋升时清除感染。
- UI：感染单位显示紫色环 + 感染条；治疗时显示绿色“+”与光束。

### 6.2 队长

**晋升**：每 3 回合（R3、R6、R9…）结算时，最多 3 名。

**选择**：

- 只从存活、未晋升、非英雄、非平民的战斗职业中选。
- 尽量 3 个不同职业；不足时从剩余候选补。
- 候选不足 3 名时，晋升所有候选，剩余名额转为全体队长伤害 +10%（最多 +50%）。

**增益**：

- 最大生命 ×2.5，当前生命同步 ×2.5。
- 伤害 ×1.3。
- 攻速 ×1.4（治疗频率同样提升）。
- 免疫感染；清除已有感染。
- 金色光环 + 队长标记。

**死亡**：

- 不转化；半径 90 爆炸，对僵尸造成 `120 + 15% 目标最大生命`。
- 对 BOSS 的百分比部分上限 800。
- 只伤僵尸，不伤人类/建筑。

**上限**：8 名；溢出转全体队长 +10% 伤害，最多 +50%。

**设计意图**：队长是“随机长出来的核心资产”，玩家不能指定，但可以通过保护/站位决定谁活下来。随机性带来每局差异，上限防止无限膨胀。

### 6.3 英雄

**获取**：击杀 BOSS 后随机赠送。

- 优先随机未拥有的英雄。
- 四种集齐后，重复随机到已拥有英雄时，该英雄永久 +20% 生命、+15% 伤害，可叠加。
- 英雄不占人口，最多 4 名。
- 英雄在部署区中央生成，满血。

**死亡**：

- 英雄免疫感染，死亡不转化。
- 阵亡后重伤休整 1 个完整回合，再下一回合以 50% HP 回到部署区。
- 若英雄是最后一名人类且阵亡，立即判负。
- 英雄不参与队长晋升。

**技能自动释放**：

- 长官导弹：每回合一次，优先 8+ 集群或 BOSS。
- 武士剑气：每次攻击 25% 概率。
- 加特林鼓舞：每 45 秒，周围友军 ≥3 时触发。
- 疫医群体治疗：每 12 秒，3+ 友军受伤时触发。
- 所有技能自动释放，不需要玩家操作；有清晰的视觉/音效提示。

### 6.4 死亡转化

| 死亡对象 | 结果 |
|---|---|
| 普通人类 | 变成普通丧尸，HP = 当回合普通丧尸的 50%，赏金 0，计入本回合剩余僵尸 |
| 队长 | 半径 90 自爆，伤害附近僵尸；不转化 |
| 英雄 | 重伤休整 1 回合，不转化 |
| 疫医转化兵 | 到期消失不转化；到期前死亡按普通人类规则变丧尸 |
| 平民 | 同普通人类，变成普通丧尸 |

**设计意图**：死亡转化让“防线被突破”有额外惩罚；队长/英雄的例外保证稀有单位不会变成敌人的战力。

### 6.5 护盾

**盾尸**

- 正面 120° 锥，200 盾值。
- 距离 >40 时：远程伤害减免 70%，先扣盾值；盾破后全额，并减速 20%。
- 近战 <40：绕过护盾，全额伤害。
- 火焰/爆炸：只享受 50% 减伤（即减免 35%）。
- 朝向 = 当前移动/攻击目标方向；玩家可以通过侧翼/绕后/导弹处理。
- UI：蓝色护盾弧 + 盾值条。

**盾兵**

- 500 HP + 250 正面盾；正面 40% 减伤；90 半径嘲讽。
- 近战同样绕过正面盾；火焰/爆炸 50% 穿盾。
- 盾值每回合整备期恢复满。
- UI：蓝色护盾弧 + 盾值条。

### 6.6 爆尸

- 优先冲向人类最密集处。
- 距离 ≤35 或 HP ≤20% → 点燃 0.8 秒引信（闪烁/滴答）。
- 引信期间被击杀 → 取消爆炸。
- 爆炸：半径 80，70 伤害，+100 感染；不伤建筑。
- 被减速/嘲讽时会延迟到达。
- 设计意图：惩罚扎堆，奖励分散与点杀。

### 6.7 母体

- 死亡：爆出 3–5 只幼体（单波全局上限 30）。
- 同时半径 120 爆炸：对建筑 200、对人类 80。
- 幼体不再爆仔；母体优先拆挡路建筑。
- 疫医转化母体：阻止死亡爆炸与爆仔（转化即“治愈”）。
- 设计意图：母体是“建筑杀手 + 数量放大器”，必须优先处理。

### 6.8 BOSS 石块

- 每 4 秒一次，瞄准人类最密集处。
- 2.0 秒红圈预警；落点锁定前 0.4 秒，非盾人类自动侧移 60px（120 速度），不离开部署区。
- 盾兵不能躲，用盾硬吃。
- 半径 70；伤害 `80 + 6R`；+30 感染。
- 不伤建筑。
- 设计意图：无微操下，用“自动侧移 + 盾兵硬吃”把预警变成可读的战术信息，而不是纯数值惩罚。

### 6.9 回合结束、失败与反卡死

**回合结束**：

1. 出生队列为空。
2. 场上僵尸数量为 0。
3. 3 秒感染结算计时结束（防止感染/爆仔/转化延迟导致误判）。
4. 进入结算。

**失败**：

- 人类数量为 0 → 1 秒死亡确认 → 游戏结束。
- 同帧人类全灭 + 最后僵尸死亡 → 判负。
- 英雄是最后一名人类且阵亡 → 判负。
- 转化兵到期导致人类为 0 → 判负。

**反卡死**：

- 僵尸 8 秒无位置进展 → 传送到最近可达格。
- 180 秒后每 30 秒全体僵尸 +30% 速度/伤害。
- 240 秒强制结算；剩余僵尸死亡；保留已获得击杀奖励。

### 6.10 机制互动表

| 互动 | 结果 |
|---|---|
| 疫医转化母体 | 不爆仔、不爆炸；变成手枪兵 |
| 疫医转化爆尸 | 不爆炸；变成手枪兵 |
| 队长爆炸 vs BOSS | 百分比伤害上限 800 |
| 爆尸爆炸 vs 建筑 | 不伤建筑 |
| 母体爆炸 vs 建筑 | 伤建筑 200 |
| BOSS 石块 vs 建筑 | 不伤建筑 |

| 感染 vs 队长/英雄 | 免疫 |
| 感染 vs 转化兵 | 会感染；到期前死亡变丧尸 |
| 路障 vs 普通丧尸 | 绕行，不攻击 |

## 7. 建筑系统

### 7.1 设计原则

- **固定槽位**：每张地图有 6–8 个建筑槽位，不能自由摆放。这样既能做“堵口/改道”，又不会出现“用建筑把基地完全围死”的漏洞。
- **普通丧尸不能攻击建筑**：它们只能绕行。只有巨人和母体可以攻击建筑；母体死亡爆炸也伤建筑。
- **建筑是战术工具，不是第二支军队**：6 种建筑覆盖阻挡、输出、续航、增益、减速、爆发。
- **建筑会死**：巨人/母体拆建筑，废墟锁槽 1 回合；玩家需要补建/换位。
- **不抢人类的人口**：建筑只花金钱和槽位，不占人口。

### 7.2 建筑总表

| 建筑 | 造价 | HP | 效果 | 占槽 |
|---|---:|---:|---|---:|
| 路障 | 50 | 800 | 阻挡普通丧尸；附近 80 内僵尸减速 25% | 1 |
| 哨塔 | 200 | 500 | 自动火力 40 DPS（10×4/s），射程 280；不可被感染 | 1 |
| 医疗站 | 150 | 400 | 半径 200 内人类 +8 HP/s，感染 -1/s；范围内治疗兵血清 +1 | 1 |
| 弹药库 | 160 | 450 | 半径 220 内人类 +15% 攻速、+10% 射程 | 1 |
| 减速陷阱 | 90 | 300 | 半径 120 内僵尸 -35% 速度；不阻挡 | 1 |
| 地雷阵 | 120 | 250 | 3 次触发，半径 80 内 120 爆炸伤害；每回合整备期重新布置 | 1 |

### 7.3 六种建筑详解

#### 路障（Barricade）

- **定位**：堵口、改道、拖时间。
- **效果**：阻挡普通丧尸（它们必须绕行）；附近 80 内僵尸减速 25%。
- **被攻击**：巨人/母体可以拆；普通丧尸不能。
- **使用建议**：放在出生点到部署区的必经之路；不要指望它挡住巨人，它的作用是让普通丧尸绕远路，把敌人送进火力覆盖区。
- **注意**：地图校验保证“所有槽位满建仍可达”；不能完全围死。

#### 哨塔（Turret）

- **定位**：稳定自动火力，不占人口。
- **效果**：40 DPS（10×4/s），射程 280；受火力科技加成；不受弹药库加成。
- **被攻击**：只有巨人/母体可以拆。
- **使用建议**：前期补输出；放在后排/侧翼；不要放在巨人第一目标位置。

#### 医疗站（Field Hospital）

- **定位**：范围续航、感染控制。
- **效果**：半径 200 内人类 +8 HP/s，感染 -1/s；范围内治疗兵血清 +1（同类不叠加）。
- **被攻击**：只有巨人/母体可以拆。
- **使用建议**：放在防线中央，覆盖最多单位；配合治疗兵形成双重续航。

#### 弹药库（Ammo Depot）

- **定位**：范围增伤。
- **效果**：半径 220 内人类 +15% 攻速、+10% 射程；同类不叠加，不同类可叠加。
- **被攻击**：只有巨人/母体可以拆。
- **使用建议**：覆盖机枪/导弹/霰弹集群；放在后排；不要为了覆盖一个单位浪费槽位。

#### 减速陷阱（Tar Trap）

- **定位**：范围减速，不阻挡。
- **效果**：半径 120 内僵尸 -35% 速度。
- **被攻击**：只有巨人/母体可以拆；普通丧尸踩过去。
- **使用建议**：放在路障绕行路线上、喷火兵/霰弹兵前方；和爆尸/狂尸波配合。

#### 地雷阵（Minefield）

- **定位**：一次性爆发、清群。
- **效果**：3 次触发，半径 80 内 120 爆炸伤害；每回合整备期自动重新布置；伤害随当回合僵尸 HP 系数成长（`120 × 1.06^(R-1)`）。
- **被攻击**：只有巨人/母体可以拆。
- **使用建议**：放在出生点附近/拐角；对密集波和母体幼体效果好。

### 7.4 槽位与地图

| 地图 | 槽位 | 建议 |
|---|---:|---|
| 郊区公路 | 6 | 2 路障 + 1 哨塔 + 1 医疗站 + 1 弹药库 + 1 减速/地雷 |
| 医院广场 | 7 | 2 路障 + 2 哨塔 + 1 医疗站 + 1 弹药库 + 1 减速/地雷 |
| 地铁站台 | 8 | 3 路障 + 2 哨塔 + 1 医疗站 + 1 弹药库 + 1 减速/地雷 |

### 7.5 摧毁、废墟与重建

- 建筑 HP 归零 → 变成废墟。
- 废墟：该槽位锁定 1 回合，不阻挡寻路；本回合剩余时间不能重建。
- 下一回合整备期，废墟自动清除，可按原价重建（不保留任何等级/状态）。
- 建筑被摧毁时，屏幕震动 + 红色提示；如果是医疗站/弹药库，防线会明显变弱。

### 7.6 寻路、绕行与防围死

- 导航网格：32px。
- 流场：从部署区反推的多源 BFS；建筑为阻挡格；建造/摧毁时重算。
- 绕行：普通丧尸不能攻击建筑，只能沿流场绕过。
- 地图校验：加载时跑一次“所有槽位满建仍可达”检查；绕行长度不得超过直连的 1.35 倍。
- 卡死处理：僵尸 8 秒无进展 → 传送到最近可达格。
- 攻城单位：巨人/母体单独判断 220 内挡路建筑，优先拆除；否则走人类流场。

### 7.7 建筑与科技/光环

- 同类建筑光环不叠加；不同类可以叠加。
- 哨塔受火力科技加成，不受弹药库加成。
- 医疗站受血清科技加成（治疗量 +5%/级）。
- 地雷阵伤害随回合成长，不吃科技。
- 建筑不享受护甲科技（建筑 HP 固定）。

### 7.8 推荐建造顺序

1. **R1–2**：路障（堵口）→ 哨塔（补输出）。
2. **R3–4**：医疗站（续航）→ 第二路障/减速陷阱。
3. **R5–6**：弹药库（增伤）→ 地雷阵（清群）。
4. **R7+**：按地图补满；优先保证医疗站/弹药库覆盖主力输出。

## 8. 地图设计

### 8.1 设计原则

- 1280×720 一屏显示，无滚动镜头。
- 只用圆形/矩形障碍，不做高低差。
- 每张地图有固定部署区、固定出生点、固定建筑槽位。
- 地图差异来自：部署区形状、出生点数量/方向、障碍物、建筑槽位分布、特殊地形。
- 每张地图都要通过“所有槽位满建仍可达”校验。

### 8.2 郊区公路（Suburban Highway）

- **难度**：1 星，教学图。
- **部署区**：底部横带 1000×160。
- **出生点**：左上、右上两个。
- **障碍**：2 辆废弃车（r36），形成两条车道。
- **建筑槽位**：6 个，沿中线分布。
- **特殊**：无；最适合新手。

## 9. 经济与难度

### 9.1 经济目标

- **正循环**：击杀 → 收入 → 扩军/科技 → 更强。
- **负循环**：战损 → 补员/重建 → 经济被吃掉。
- **节奏**：收入应该让玩家“刚好”能补强，但不能无限滚雪球。
- **金钱出口**：招募、建筑、科技、补员、重建；科技是后期主要出口。

### 9.2 初始资源与人口

- 初始金钱：**400**。
- 初始人口上限：**10**。
- 人口上限公式：`min(80, 8 + 2 × R)`。
- 平民上限：8。
- 英雄不占人口；转化兵不占人口，最多 15。

### 9.3 收入

| 来源 | 数值 |

| 击杀（普通/精英/幼体） | 基础赏金 × `(1 + 0.03 × (R-1))` |

| 平民 | 每个存活平民 +12/回合 |
| BOSS | `400 + 50 × R` |

**击杀基础赏金**：普通 6、狂尸 9、盾尸 18、爆尸 12、母体 35、巨人 60、幼体 2、转化丧尸 0。

### 9.9 防滚雪球

- 人口上限随回合增长，防止前期无限爆兵。

- 战损/建筑被拆会吃掉经济，形成自然止血。
- 僵尸 HP 指数增长，玩家战力靠人口/科技/队长/英雄多线成长；单一 DPS 兵种会被精英组合克制。
- 反卡死规则防止“拖着不打”刷钱。

## 10. 自动战斗 AI 与战斗规则

### 10.1 僵尸 AI

**状态机**：

```
SPAWN → APPROACH → ATTACK → (SIEGE) → DEAD
```

- **SPAWN**：从出生点出现，1 秒传送门预警；短暂无敌/无碰撞（0.3 秒）。
- **APPROACH**：沿流场走向部署区；进入部署区后直接朝目标人类转向。
- **ATTACK**：进入攻击距离（半径和 + 4）后停下，按攻击间隔造成伤害。
- **SIEGE**（巨人/母体）：如果 220 内有挡路建筑，优先攻击建筑；否则回退到 APPROACH/ATTACK。
- **DEAD**：播放死亡效果；母体触发爆仔/爆炸；普通人类转化丧尸被击杀时无赏金。

**目标选择**：

- 普通/狂尸/盾尸/爆尸/幼体：最近人类；盾兵 90 半径嘲讽优先级更高。
- 巨人/母体：220 内挡路建筑 > 最近人类。
- BOSS：人类最密集处（石块）；近身践踏范围内最近人类。
- 爆尸：人类最密集处；距离 ≤35 或 HP ≤20% 进入引信。
- 如果没有任何人类：走向部署区中心；若部署区也没有目标，走向地图中心（用于反卡死）。

**寻路**：

- 32px 网格 + 多源 BFS 流场（从部署区反推）。
- 建筑为阻挡格；建造/摧毁时重算。
- 进入部署区后，流场权重降低，直接朝目标转向。
- 分离力：空间哈希 64px，取最多 8 个邻居做软推挤；禁止 O(n²)。
- 卡住 8 秒：传送到最近可达格。

### 10.2 人类 AI

> v1.1 起，人类不再原地站桩：所有单位都有自主移动、寻医与闪避行为。

**状态机**：

```
IDLE/GUARD → ACQUIRE → MOVE(追击) → ATTACK / HEAL → RETURN
                     ↘ CARE(寻找医疗站/治疗兵) ↗
                     ↘ DODGE(闪避狂尸冲刺)      ↗
```

- **GUARD**：没有目标时站在玩家布置的 home 点。
- **ACQUIRE/ADVANCE**：视野内出现僵尸且不在射程内时，主动离开部署区追击；追击范围以 home 为圆心、按兵种设定活动半径，超出后停在边界，不会全队失控冲进出生点。
- **ATTACK/HEAL**：进入射程/治疗范围后停下执行；换弹、冷却在状态内处理。
- **RETURN**：视野内没有目标时以略高于移动速度回防；每回合开始时所有单位强制回到玩家布置的站位。
- **CARE**：HP < 60% 或感染 ≥ 30 时，自动前往最近的医疗站或治疗兵；恢复到 88% HP / 感染 ≤ 8 后归队。治疗兵会主动迎向 460 半径内最需要救治的伤员（已处于医疗站范围内的伤员除外）。
- **DODGE**：狂尸处于冲刺状态、朝自己冲来且距离 132px 内时，非盾单位向偏离冲刺线的一侧侧移约 0.35 秒；盾兵不闪避，据守硬吃。
- **DEAD**：普通人类变丧尸；队长爆炸；英雄重伤。

**索敌优先级**（保持原设计）：

| 单位 | 优先级 |
|---|---|
| 手枪/机枪/哨塔 | 最近目标 |
| 霰弹/喷火 | 扇形内目标密度最高处 |
| 导弹 | 最大集群；有攻城单位时优先攻城单位 |
| 治疗兵 | 感染 ≥50；其次血量百分比最低 |
| 盾兵 | 视野内最近目标，推进到近战距离 |
| 武士 | 180 内最近目标；优先盾尸/狂尸 |
| 长官 | 最近/高威胁；导弹自动择机 |
| 加特林 | 最近目标；鼓舞自动 |
| 疫医 | 治疗优先；无治疗目标时攻击最近僵尸 |

**移动参数**（见 `src/data/humans.js` / `heroes.js` / `humanAi`）：

| 单位 | 移动速度 | 视野 | 活动半径 |
|---|---:|---:|---:|
| 手枪兵 | 68 | 340 | 420 |
| 霰弹兵 | 80 | 280 | 340 |
| 机枪兵 | 56 | 360 | 400 |
| 喷火兵 | 78 | 250 | 320 |
| 导弹兵 | 50 | 480 | 460 |
| 盾兵 | 64 | 220 | 220 |
| 治疗兵 | 90 | 200 | 240 |
| 平民 | 96 | — | —（遇袭撤离） |
| 长官 / 武士 / 加特林 / 疫医 | 62 / 70 / 54 / 84 | 380 / 300 / 340 / 260 | 400 / 340 / 360 / 300 |

**站位与可读性**：

- 人类会绕开车辆、柱子与建筑，不会直线卡死；单位之间保留轻微分离，避免全部叠在同一个目标或医疗点。
- 盾兵仍靠 90 半径嘲讽吸怪，是唯一不闪避冲刺的兵种。
- 平民不参战：190px 内有僵尸就朝远离威胁的方向撤离，受伤/感染后同样会寻医。
- 头顶 UI：绿色虚线 = 正在前往医疗目标；绿色十字徽标 = 处于寻医状态；箭头 = 当前移动方向；白色速度线 = 闪避冲刺。
- BOSS 石块侧移只移动 60px，与自主移动叠加，不改变整体阵型。

### 10.3 寻路、碰撞与分离

- 世界 1280×720；导航网格 32px（40×23 格）。
- 建筑占格；普通丧尸绕行；攻城单位可拆。
- 空间哈希 64px：索敌、碰撞、分离、AOE 查询。
- 圆-圆碰撞；僵尸之间软推挤；人类之间做轻微分离，避免叠在同一点。人类移动会绕开圆形障碍与建筑。
- 投射物命中用空间哈希查询；爆炸用半径查询。
- 每帧重算流场只在建造/摧毁时发生；平时只读。

| 类型 | 表现 | 命中 |
|---|---|---|
| 子弹 | 快速曳光 | 射线/瞬时；显示 2–3 帧曳光 |
| 霰弹 | 5 条短射线 | 扇形；距离衰减 |
| 火焰 | 锥形粒子 | 每 0.125 秒对锥内目标判定 |
| 火箭 | 实体投射物 | 落点半径 60 爆炸 |
| 药瓶 | 实体投射物 | 落点半径 50 爆炸 |
| BOSS 石块 | 抛物线 + 红圈 | 落点半径 70 爆炸 |
| 导弹支援 | 3 枚落点 | 半径 140 爆炸 |
| 近战 | 挥砍/碰撞 | 距离判定 |

- 玩家单位无友伤。
- 爆尸爆炸只伤人类；母体爆炸伤人类和建筑；队长爆炸只伤僵尸；BOSS 石块只伤人类。
- 伤害数字上限 50 个；超出时合并/丢弃。

### 10.5 伤害管线

```
伤害来源
  → 检查目标是否存活
  → 护盾/减伤（正面弧、距离、伤害类型）
  → 扣 HP
  → 感染/灼烧/减速等状态
  → 死亡检查
  → 死亡效果（变丧尸/爆仔/爆炸/重伤）
  → 赏金/特效/统计
```

**护盾判定顺序**：

1. 目标是否有盾（盾尸/盾兵）。
2. 攻击是否来自正面 120° 且距离 >40。
3. 伤害类型：远程 → 70% 减免；火焰/爆炸 → 50% 减免；近战 → 绕过。
4. 先扣盾值，盾破后按全额。
5. 盾破减速 20%。

### 10.6 状态效果

| 状态 | 来源 | 效果 | 清除 |
|---|---|---|---|
| 感染 | 僵尸命中/爆尸/石块 | 持续掉血 0.02%/感染值/秒 | 血清/疫医/医疗站/回合隔离 |
| 灼烧 | 喷火兵 | 5/秒 × 3 秒 | 时间 |
| 减速 | 路障/减速陷阱/盾破 | -25% / -35% / -20% | 离开范围/时间 |
| 嘲讽 | 盾兵 | 僵尸优先攻击盾兵 | 离开 90 半径 |
| 鼓舞 | 加特林 | +30% 攻速 8 秒 | 时间 |
| 重伤 | 英雄死亡 | 休整 1 回合 | 下一回合 |

### 10.7 回合判定与边缘情况

| 情况 | 处理 |
|---|---|
| 最后一只僵尸和最后一名人类同帧死亡 | 判负 |
| 母体死亡爆仔，幼体在结算计时内出现 | 等待幼体被清 |
| 爆尸引信期间被击杀 | 取消爆炸 |
| 疫医转化母体 | 不爆仔/不爆炸 |
| 转化兵到期与回合结算同帧 | 先结算死亡，再判定人类是否为 0 |
| 英雄重伤期间人类全灭 | 判负 |
| 建筑被摧毁后槽位锁定 | 1 回合后解锁 |
| 人类为 0 但僵尸还在 | 1 秒确认后判负 |
| 僵尸卡住 | 8 秒传送；180 秒狂暴；240 秒强制结算 |
| 玩家暂停 | 所有模拟停止；UI 可操作 |

### 10.8 可读性规则

- 每个攻击/技能都有可辨认的视觉：枪口闪光、曳光、火焰锥、火箭尾迹、治疗光束、护盾弧、感染紫环。
- 人类自主行为同样可读：绿色虚线指向医疗目标、绿色十字徽标表示寻医、移动箭头表示追击/回防、白色速度线表示闪避。
- BOSS 石块有 2 秒红圈；红圈内单位会侧移，玩家能看懂“为什么要动”。
- 母体死亡有爆仔动画；爆尸有引信闪烁；盾尸有护盾弧；队长有金环；英雄有星标。
- 血条只画受伤单位；满血单位不画，减少视觉噪音。
- 伤害数字可关；屏幕震动可关。

## 12. 技术方案

### 12.1 技术选型

- **零依赖、零构建、经典 script**：`index.html` + `src/` 多文件，按依赖顺序加载，挂 `window.ZG`。
- 不用 ES module，保证 `file://` 双击可玩；不用 npm/打包器。
- Canvas 2D 渲染战场；DOM 渲染 HUD/商店/科技/弹窗。
- localStorage 存最佳回合与设置；全部 try/catch。
- 目标浏览器：Chrome / Edge 最新版；桌面 1280×720 以上。

### 12.2 文件结构

```
F:\claudecode\games\zombie-defense\
  index.html
  src\
    core\
      constants.js      // 颜色、尺寸、速度、层
      rng.js            // mulberry32、种子流
      eventbus.js       // 事件总线
      state.js          // 全局状态
    data\
      humans.js         // 8 职业 + 队长
      zombies.js        // 6 普通 + 幼体 + BOSS
      heroes.js         // 4 英雄
      buildings.js      // 6 建筑
      maps.js           // 3 地图、出生点、槽位、障碍
      waves.js          // 数量/构成/解锁
      balance.js        // 数值公式、科技、经济
    sim\
      spawner.js        // 出生队列/批次
      pathing.js        // 流场/导航网格
      ai.js             // 索敌/状态机/走位
      combat.js         // 伤害/护盾/死亡/赏金
      infection.js      // 感染/血清/灼烧/减速
```

### 12.3 主循环与时间步

- 固定步长：`STEP = 1000/60` 毫秒。
- 累加器：每帧最多追 5 个模拟步，防止卡顿螺旋。
- 速度：1x/2x/3x = 每渲染帧执行 1/2/3 个模拟步；暂停 = 0。
- 渲染与模拟解耦；不需要插值（圆形单位，60Hz 足够）。
- 输入在渲染帧处理；游戏状态只在模拟步更新。

### 12.4 实体与系统

- **人类**：id、type、x/y、hp/maxHp、shield、infection、target、cooldown、captain/hero、状态。
- **僵尸**：id、type、x/y、hp/maxHp、shield、target、speed、cooldown、状态（冲刺/引信/攻城）。
- **建筑**：id、type、slot、x/y、hp/maxHp、cooldown、aura。
- **投射物**：type、x/y、vx/vy、damage、radius、owner、life。
- **粒子/伤害数字**：对象池。
- **系统顺序**：出生 → 寻路 → AI → 移动 → 碰撞 → 攻击 → 投射物 → 伤害 → 死亡/结算 → 经济 → 渲染。

### 12.5 流场与空间哈希

- 导航网格 32px；地图加载时构建阻挡格。
- 流场：从部署区所有可达格反向 BFS；每格存方向/距离。
- 建造/摧毁时重算流场（整备期低频，战斗中建筑被拆时重算一次）。
- 攻城单位：单独判断建筑目标；不需要第二张流场。
- 空间哈希：64px 格子；每帧重建或增量维护；查询半径/最近邻居。
- 每个僵尸最多取 8 个邻居做分离；避免 O(n²)。

### 12.6 对象池与性能

- 对象池：僵尸、投射物、粒子、伤害数字。
- 背景预渲染到离屏 canvas；地图静态元素只画一次。
- 血条只画受伤单位；满血不画。
- 伤害数字上限 50；粒子上限 250。
- 绘制顺序：背景 → 地面效果 → 建筑 → 僵尸 → 人类 → 投射物 → 粒子 → UI 覆盖。
- 目标：模拟 ≤4ms、渲染 ≤6ms、总计 ≤12ms/帧；300 僵尸 + 99 人类 + 100 投射物。
- 如果超预算：减少粒子、合并伤害数字、跳过远处血条、降低分离邻居数。

### 12.7 确定性与测试钩子

- `mulberry32` 种子随机；出生/晋升/英雄/抖动使用独立 RNG 流。
- 模拟内禁用 `Math.random`；所有随机走 `rng`。
- 暴露 `window.__game`：

```js
__game.state          // 'menu' | 'prep' | 'battle' | 'settlement' | 'over'
__game.round / money / population / seed
__game.units / zombies / buildings / projectiles
__game.snapshot()     // 状态的稳定哈希/快照
__game.startRound()
__game.spawn(type, x, y)
__game.damage(targetId, amount, type)
__game.infect(targetId, amount)
__game.forcePromotion(n)
__game.forceHero(type)
__game.tick(n)        // 推进 n 个固定步，确定性
__game.setSpeed(1|2|3)
__game.stopLoop() / resumeLoop()
```

- 无头 bot：给定固定策略（补兵/建造/科技），跑 20/40 回合，输出回合时长、存活人口、经济、DPS 等指标，用于回归与调参。
- 每次改数值后跑一次 20/40 回合 bot，避免“修一个坏一个”。

### 12.8 存档与设置

- `localStorage` 键：`zd_best_<map>`、`zd_settings`。
- 存：每张图最佳回合、速度、伤害数字开关、震动开关、静音、引导是否看过。
- 全部 try/catch；失败不影响游戏。
- 不存单局进度（首版不做中途存档）。

### 12.9 浏览器兼容与运行

- 双击 `index.html` 即玩；经典 script 避免 `file://` 的模块 CORS 问题。
- 不支持 IE；不保证 Safari 旧版。
- 窗口缩放：Canvas 按整数倍/等比缩放，保持 16:9；DOM HUD 跟随缩放。
- 移动端：M4 做横屏/触控/安全区适配，详见第 13.3.3 节；桌面鼠标体验仍优先。

## 13. 发布与包装

> 目标分四阶段：**先让朋友和手机能玩** → **可选桌面软件** → **可选手机 App** → **后期 Steam**。四个阶段共用同一套静态游戏代码；包装层只负责窗口、存档、分享和平台适配，不侵入游戏逻辑。

### 13.1 发布路线

| 阶段 | 目标 | 产物 | 优先级 |
|---|---|---|---|
| P1 网页 / PWA | 发链接给朋友、手机浏览器/主屏可玩 | 静态网页 + 二维码 | **必做** |
| P2 桌面软件 | 可双击的 Windows 绿色版/安装包 | Electron 或 Tauri 的 exe/msi | 可选 |
| P3 手机 App | 应用商店、推送等 | Capacitor apk/ipa | 可选 |
| P4 Steam | 上架 Steam | Steamworks 包 | 后期 |

推荐顺序：**P1 必做；P2 看朋友是否需要 exe；P3 非必要；P4 等内容完整、40 回合平衡跑通后再做。**

### 13.2 方案对比

| 方案 | 产物 | 体积 | 运行时 | 适合 |
|---|---|---:|---|---|
| PWA / 静态网页 | 链接、二维码、可安装网页 | 几乎 0 | 浏览器 | 朋友、手机、离线 |
| Tauri | exe / msi | 3–10 MB | 系统 WebView2 | 轻量 Windows 软件 |
| Electron | exe / 安装包 | 80–150 MB | 自带 Chromium | 快速打包、跨平台 |
| Neutralino.js | exe | 2–5 MB | 系统 WebView | 轻量，但生态小 |
| Capacitor | apk / ipa | 视壳而定 | 系统 WebView | 手机应用商店 |
| Steam | Steam 包 | 视打包方式 | Steam 客户端 | 后期发行 |

对本项目的判断：

- **PWA 是主路径**：零安装、发链接就能玩，手机浏览器直接打开；安装到主屏后像 App。
- **Tauri 是桌面首选**（如果愿意装 Rust）：体积极小、启动快；Windows 11 自带 WebView2。
- **Electron 是最省事的桌面路线**：你已有 Electron 经验，生态成熟；缺点是体积大、国内安装要配 npmmirror。
- **Capacitor 只有在上应用商店/需要推送时才值得做**；当前 UI 是桌面横屏布局，手机端需要专门适配。
- **Steam 不着急**：先把内容和 40 回合平衡做完，再考虑 Steamworks。

### 13.3 第一阶段：PWA + 静态网页（朋友 + 手机）

#### 13.3.1 托管与链接

- 游戏保持纯静态：`index.html` + `src/` + `manifest.webmanifest` + `sw.js` + 图标，不需要后端。
- 首选 **GitHub Pages**：沿用你现有的发布方式（SSH 推送，Pages 可访问）。地址形如：
  `https://charanie.github.io/zombie-defense/`
- 备选：Cloudflare Pages、Netlify、Vercel；国内访问慢时可换国内静态托管/CDN（自定义域名可能涉及备案）。
- 必须使用 **HTTPS**：Service Worker 和 PWA 安装都要求 HTTPS（localhost 例外）。
- 生成二维码指向该地址，发给朋友；二维码可以放进 README、分享图或聊天。
- 页面加 OG 标签（`og:title`、`og:description`、`og:image`、`theme-color`），微信/QQ 分享时至少能显示标题和缩略图。
- 无后端、无账号；存档全部在本地。

#### 13.3.2 PWA 配置

`manifest.webmanifest` 关键字段：

```json

  "start_url": "./",
  "scope": "./",
  "display": "standalone",
  "orientation": "landscape",
  "background_color": "#0E1420",
  "theme_color": "#0E1420",

    { "src": "icons/icon-192.png", "sizes": "192x192", "type": "image/png" },

    { "src": "icons/icon-maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]

```

`sw.js` 策略：

- **Cache First** 缓存游戏壳：`index.html`、`src/**/*.js`、manifest、图标。
- 缓存名带版本号（如 `zd-v1.0.0`）；发新版本时换版本号并清理旧缓存。
- 首次访问后离线可玩；更新时显示“新版本已就绪，点击刷新”，不要强制打断战斗。
- 注册放在 `main.js`，只在 HTTPS/localhost 下注册；失败不影响游戏。
- 开发阶段可以禁用 Service Worker，避免缓存干扰调试；发布构建再启用。

安装入口：

- Android/桌面 Chromium：监听 `beforeinstallprompt`，显示“安装到桌面/主屏”按钮。
- iOS Safari：没有 `beforeinstallprompt`，显示手动指引“分享 → 添加到主屏幕”。
- 已安装（`display-mode: standalone`）时隐藏安装按钮。

#### 13.3.3 手机适配

- **横屏优先**：游戏是 16:9；竖屏时显示“请横屏游玩”遮罩，提供“仍然继续”按钮（不强制锁死）。
- **Canvas 缩放**：内部 1280×720；CSS 等比缩放到视口，留黑边；不改变逻辑坐标。
- **视口**：`viewport-fit=cover`、`user-scalable=no`；Canvas 设 `touch-action: none`，禁用双击缩放和页面滚动。
- **安全区**：HUD 和底部面板使用 `env(safe-area-inset-*)`，避开刘海和手势条。
- **触控操作**：
  - 点卡片 → 点部署区放置；点已有人类 → 拖动；点空白 → 取消。
  - 没有 hover：所有 tooltip 改为“点按显示”，再点一次关闭。
  - 触控目标最小 44×44px；按钮间距足够，避免误触。
  - 底部招募/建筑/科技面板改为可折叠抽屉；战斗时收起为一条窄栏。
- **性能档位**（按 `pointer: coarse` 或设备内存自动切换）：
  - DPR 上限 1.5（桌面可 2）。
  - 粒子上限 120（桌面 250）。
  - 伤害数字默认关闭；屏幕震动默认关闭。
  - 同屏僵尸上限 200（桌面 300）；超出时延迟出生，不丢怪。
  - 背景预渲染、血条只画受伤单位、对象池照常使用。
- **音频**：首次点击“开始”时初始化 Web Audio；默认音量适中；提供静音按钮。
- **全屏/方向**：Android Chrome 可 `requestFullscreen` + `screen.orientation.lock('landscape')`；iOS 不支持方向锁定，用横屏遮罩兜底。
- **测试机型**：iPhone Safari、Android Chrome、微信内置浏览器、QQ 浏览器、桌面 Edge/Chrome。

#### 13.3.4 微信 / iOS / QQ 注意事项

- **微信内置浏览器**：
  - 普通 H5 链接可以直接玩；但**不能安装 PWA**，Service Worker 也可能受限。
  - 检测 `MicroMessenger` UA，顶部显示“建议在浏览器中打开”提示；不要反复弹窗。
  - 微信分享预览由 OG 标签影响，但微信有缓存；需要更精细的分享卡片时才考虑微信 JS-SDK（要公众号、域名校验，成本高，首版不做）。
- **iOS Safari**：
  - 没有安装提示；用“分享 → 添加到主屏幕”手动安装。
  - Service Worker 可用；音频必须由用户手势触发。
  - 全屏 API 有限；用 `viewport-fit=cover` + 安全区适配。
- **QQ 浏览器/其他国产浏览器**：按普通 H5 处理；测试横屏、音效、触摸放置。
- **分享文案**：一句话“点开就能玩，横屏更佳”；附二维码；不要用短链服务，避免失效。

#### 13.3.5 分享与二维码

- 手机端优先用 `navigator.share` 分享链接；不支持时复制链接。
- 生成 512×512 二维码，指向 Pages 地址；放在 README、分享图、聊天里。
- 社交预览图 1200×630：标题 + 圆形单位 + BOSS 剪影 + 二维码（可选）。
- 菜单显示版本号（如 `v0.4.0`），方便朋友反馈“我玩的是哪版”。

### 13.4 第二阶段：桌面软件（可选）

如果朋友不想开浏览器，或者你想发一个“双击即玩”的 exe，就加桌面壳。**游戏代码不变**，壳只负责窗口、存档和图标。

#### 13.4.1 Electron 路线（最省事）

- 适用：你已经用过 Electron，Node/npm 环境现成；想要 Windows/macOS/Linux 一套代码。
- 目录建议：

```
desktop/electron/
  package.json
  main.js
  preload.js
  icons/icon.ico
```

- `main.js` 要点：
  - `BrowserWindow({ width: 1280, height: 720, minWidth: 960, minHeight: 540, useContentSize: true, autoHideMenuBar: true })`
  - `loadFile('../../index.html')`（或把游戏文件复制进 `dist/` 再加载）。
  - `nodeIntegration: false`、`contextIsolation: true`；只通过 `preload.js` 暴露最小存档 API。
  - 支持 F11 全屏；窗口大小/位置可记忆（可选）。
- 存档：
  - 默认 `app.getPath('userData')/save.json`。
  - 绿色版：如果存在 `PORTABLE_EXECUTABLE_DIR`，把 `save.json` 放在 exe 同目录；否则回退用户目录。
  - 预加载层暴露 `saveGame(json)` / `loadGame()`；网页端仍用 `localStorage`，由 `platform.js` 统一。
- 构建：
  - 依赖：`electron`、`electron-builder`。
  - 目标：`portable`（单文件绿色版）+ `nsis`（安装包）。
  - 图标 `.ico`；`asar: true`；产物名带版本号。
  - 国内镜像：设置 `ELECTRON_MIRROR` 与 `ELECTRON_BUILDER_BINARIES_MIRROR` 到 npmmirror（你之前踩过这个坑）。
- 体积/内存：安装包约 80–150MB；运行内存约 150–300MB。
- 签名：未签名 exe 首次运行会触发 SmartScreen；自己/朋友用可点“更多信息 → 仍要运行”；公开分发建议代码签名或走 Microsoft Store。

#### 13.4.2 Tauri 路线（体积最小）

- 适用：愿意装 Rust 工具链；想要 3–10MB 的 exe/msi。
- 前置：Rust + Cargo；Windows 11 自带 WebView2（Win10 可能需要安装 WebView2 Runtime）。
- 目录建议：

```
desktop/tauri/
  src-tauri/
    tauri.conf.json
    src/main.rs
  dist/                ← 游戏静态文件
```

- `tauri.conf.json` 要点：
  - `build.frontendDist` 指向 `dist/`。
  - 窗口 1280×720、可缩放、标题“尸潮防线”。
  - `bundle.targets` 选 `nsis` / `msi`；图标用 `.ico`。
- 存档：Rust command `save_game` / `load_game` 写入 `app_data_dir`；或使用 `tauri-plugin-store`；网页端回退 `localStorage`。
- 构建：`cargo tauri build`；首次构建需要下载 crates，国内可配 crates 镜像。
- 体积/内存：安装包约 3–10MB；内存明显低于 Electron。
- 签名：同样有 SmartScreen 问题；公开分发需签名。

#### 13.4.3 存档、窗口与签名

- **统一存档抽象**：`src/core/platform.js`
  - `Platform.isMobile` / `isStandalone` / `isWeChat` / `isDesktop`
  - `Platform.save(data)` / `Platform.load()`（异步、JSON、带版本号）
  - `Platform.share(text, url)` / `Platform.vibrate(ms)` / `Platform.requestFullscreen()`
  - 网页用 `localStorage`；Electron/Tauri 用文件；失败时回退内存并提示。
- **存档兼容**：存档带 `version` 字段；升级时做迁移，不直接丢弃。
- **导出/导入**：提供一个“导出存档 JSON / 导入存档”按钮，方便换设备或备份。
- **窗口**：记住窗口大小/位置（可选）；全屏切换；关闭前如果正在战斗中，提示确认（可选）。
- **签名**：个人/朋友分发可以先不签名；公开下载页写清“Windows 可能提示未知发布者”。要正式发行再做代码签名或 Microsoft Store。

### 13.5 第三阶段：手机 App（可选）

- 什么时候做：需要上架应用商店、推送通知、应用内购买，或 PWA 在目标机型上体验不够好。
- 方案：**Capacitor** 包同一套 web 构建；Android 用 Android Studio，iOS 需要 macOS + Xcode。
- 必须做的适配：
  - 13.3.3 的全部手机适配。
  - 刘海/安全区、横屏锁定、返回键处理。
  - 存档迁移（WebView localStorage 在 App 内可用，但换壳会丢；建议文件存档 + 导出/导入）。
  - 应用图标、启动图、隐私政策、商店截图。
- 成本：Android 较低；iOS 需要开发者账号（约 99 美元/年）和审核；首版不建议。
- 结论：**PWA 足够覆盖“发给朋友 + 手机玩”；Capacitor 留到有明确上架需求时再做。**

### 13.6 第四阶段：Steam（后期）

- 前置：内容完整（M4 完成）、40 回合平衡、性能稳定、至少一轮外部试玩。
- Steam Direct：每个游戏约 100 美元上架费；需要 Steamworks 账号、商店页、税务/银行信息。
- 打包：用 Electron 或 Tauri 的 Windows 构建；通过 SteamPipe 上传。
- Steamworks 集成：
  - 成就（如“活过 20 回合”“击杀 10 个 BOSS”）。
  - Steam Cloud 存档（把 `Platform.save` 接到 Steam Cloud）。
  - 可选：Steam Deck 验证、排行榜。
- Steam Deck：1280×800，触控板可模拟鼠标；建议加手柄/触控板支持与更大 UI；验证 Proton 兼容。
- 商店素材：胶囊图、截图、预告片、短描述、长描述、标签、年龄分级、隐私政策。
- 不建议早期接 Steamworks：先保持 `platform.js` 抽象，等内容稳定再一次性接。

### 13.7 平台抽象层

无论最终发几个平台，游戏逻辑只调用 `Platform`，不直接散落 `localStorage` / `window.electron` / `window.__TAURI__`：

```js
// src/core/platform.js（示意）
Platform = {
  isMobile, isStandalone, isWeChat, isDesktop,
  quality: { dprCap, particleCap, zombieCap, shake, damageNumbers },
  save(data), load(), exportSave(), importSave(file),
  share(text, url), vibrate(ms), requestFullscreen()
}
```

- 网页：`localStorage` + `navigator.share`。
- Electron：`preload` 暴露的 `saveGame/loadGame`。
- Tauri：`invoke('save_game')` / `invoke('load_game')`。
- Capacitor：文件系统插件 + 分享插件。
- Steam：Steam Cloud 适配器。
- 这样 M1–M4 只需要写一次游戏，发布时只换适配器。

### 15.3 待定项与设计判断

以下 11 条是设计过程中为了让系统闭环而做的判断，已在本文档中生效；如果用户不同意，改动成本很低：

1. **人口上限**用 `min(80, 8 + 2R)`，而不是固定 35。
2. **队长上限 8 名**，溢出转全体队长 +10% 伤害（最多 +50%）。
3. **平民不参与队长晋升**；如果希望平民也能当“村长”，可改为晋升后收入 ×2.5。
4. **英雄统一免疫感染（含疫医）**；阵亡后重伤休整 1 回合，下一回合 50% HP 回归。若想更硬核，可改为永久死亡。
5. **BOSS 石块只伤人类，不伤建筑**；严格遵循“只有巨人和母体拆建筑”。BOSS 波对建筑的威胁由护卫里的巨人/母体承担。
6. **回合结束感染压到 30**，有治疗兵则清零；防止全自动下感染滚雪球。
7. **反卡死规则**：8 秒传送、180 秒狂暴、240 秒强制结算。
8. **初始 400 金、僵尸数量 `6+5R`、HP `1.06^(R-1)`**；计划书第 9 章附推演表。
9. **科技树数值**（费用指数 1.45/1.40）是首版建议值，标注为可调。
10. **地图主题**采用郊区公路 / 医院广场 / 地铁站台。
11. **疫医调整**：HP 800；群体治疗每 12 秒/半径 180/+70 HP/驱散 30；转化兵不占人口、3 个完整回合后消失、同时最多 15 名、每回合最多 5 个。
