## v1.5.0 已完成

- **地图数据分层**：`zones / spawns / decor / terrain / obstacles`；`obstacles` 仍是唯一碰撞真相，`decor` 纯视觉且用固定种子 LCG 生成噪声。
- **地铁双通道**：U 形活动区（北通道 `y 160..300`、南通道 `y 420..560`、末端大厅 `x 1000..1240`）；中央设备带与上下轨道不可通行；只从西侧两个隧道口 `(-20, 230)` / `(-20, 490)` 出怪。
- **区域约束**：`ZG.MapZone` 统一回答 contains / containsCircle / clamp / center / mask；放置、建筑、人类移动、小队阵位、拖拽、僵尸移动、BOSS 召唤与冲刺全部走同一套活动区；区域外放置返回 `outside-zone`。
- **流场**：有 zones 的地图把区域外格子写进 `blocked`，并使用水平优先加权最短路（水平 10 / 垂直 12）；无 zones 的两图保持 v1.4 BFS、RNG 与移动钳制不变。
- **地图绘制**：新增 `ZG.MapLayer`（主题底色 / 道路 / 活动区 / 标线 / 噪声 / 大件装饰 / terrain / 障碍 / 网格 / 区域压暗 / 暗角），三图各 ≥10 类装饰、≥4 个可碰撞大件；缩略图由同模块绘制。
- **特效体系**：新增 `ZG.Fx`（18 类新效果 + v1.4 效果，world / air / screen 三层）；粒子新增 `spark/smoke/shard/star`、自旋、缩放与 additive；新增 `missile/slash/stomp/rockBreak/fuse` 音效。
- **人类技能表现**：长官 3 个落点锁定圈、武士三层弧光、加特林鼓舞金环、疫医群疗绿波纹、火箭/毒瓶拖尾、治疗光束十字、头顶技能状态环。
- **僵尸特殊攻击**：坦克投石预警/落地冲击/6 秒地裂、践踏双环、裂爪冲刺划痕与硬直星环、腐吐者蓄力球、母巢符文阵与破土、爆尸引信进度环 + 膨胀 + 毒雾、盾尸拦截火花、巨人拆墙冲击。
- **地图观感**：郊区公路、医院广场、地铁站台各有一眼可辨的主题与装饰；地铁图区域外压暗 + 黄色安全虚线让可玩区一眼可见。

- 竖屏手机视野较小（世界等比居中），建议横屏。
- 音效为 Web Audio 程序生成，音量/延迟仍以真机为准。
